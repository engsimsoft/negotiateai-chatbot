## Новый инструмент: exportDocument

### Описание

Экспорт артефакта в формат DOCX для скачивания.

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| documentId | string | ID артефакта для экспорта |
| filename | string | Имя файла (без расширения) |

### Возвращает

| Поле | Тип | Описание |
|------|-----|----------|
| success | boolean | Успешность операции |
| downloadUrl | string | URL для скачивания файла |
| filename | string | Полное имя файла с расширением |

### Реализация

Рекомендуемая библиотека: `docx` (npm package)

Альтернативы:
- `officegen`
- `docxtemplater`

### UI

Добавить кнопку "Скачать DOCX" в интерфейс артефакта:

```
┌─────────────────────────────────────────┐
│ 📄 Перевод документа                    │
├─────────────────────────────────────────┤
│                                         │
│ [Содержимое артефакта]                  │
│                                         │
├─────────────────────────────────────────┤
│ [Копировать]  [Скачать DOCX]            │
└─────────────────────────────────────────┘
```

## Логика работы

### Создание чата

1. Пользователь заходит на главную
2. Показывается список его агентов (фильтр по роли пользователя)
3. Пользователь кликает на агента
4. Создаётся новый чат с `agentId`
5. В чат добавляется приветственное сообщение от агента
6. Пользователь пишет первое сообщение

### Генерация ответа

1. Получаем `agentId` из чата
2. Загружаем промпт агента
3. Используем промпт как system prompt для AI
4. AI использует указанные в промпте инструменты
5. Генерируем ответ

### Экспорт в DOCX

1. Пользователь нажимает "Скачать DOCX" на артефакте
2. Вызывается exportDocument с ID артефакта
3. Генерируется DOCX файл
4. Файл скачивается в браузере
