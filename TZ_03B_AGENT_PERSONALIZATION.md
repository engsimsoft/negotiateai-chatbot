**Проект:** Simply (на базе Family AI Assistant)
**Версия:** 1.1
**Дата:** 2026-01-28
**Этап:** 3B (после профиля пользователя)

---

## 🎯 Цель

Реализовать диалоговую персонализацию агентов, где пользователь создаёт персональную копию агента через разговор с Помощником. Никаких форм — только простые вопросы и кнопки.

**Важно:** Данные пользователя (имя, обращение) берутся из профиля (ТЗ-3A). Здесь настраивается только сам агент.

## 🎨 Философия UX

**Принцип:** Пользователь не заполняет форму — он отвечает на простые вопросы.

**Что настраивается:**
- ✅ Имя агента (не пользователя!)
- ✅ Стиль общения агента
- ✅ Специализация агента
- ✅ Дополнительный контекст для этого агента

**Что НЕ настраивается (берётся из профиля):**
- ❌ Имя пользователя
- ❌ Обращение (ты/вы)
- ❌ Общий контекст пользователя

## 🔧 Техническая реализация

### Диалог — скриптованный, не AI

**Важно:** Диалог персонализации НЕ использует LLM. Это фиксированный скрипт с условными переходами.

```typescript
type PersonalizationStep = {
  id: string;
  message: string;
  inputType: 'text' | 'buttons' | 'text-optional';
  options?: { label: string; value: string; description?: string }[];
  placeholder?: string;
  hint?: string;
  defaultValue?: string;
  nextStep: string;
};

const steps: PersonalizationStep[] = [
  {
    id: 'name',
    message: 'Отлично! Давай настроим {agentName} под тебя.\n\nКак хочешь его назвать?',
    inputType: 'text',
    placeholder: 'Мой маркетолог',
    hint: 'Например: "Маркетолог Макс", "Мой SMM-щик"',
    defaultValue: 'Мой {agentName}',
    nextStep: 'style'
  },
  {
    id: 'style',
    message: '"{name}" — отличное имя!\n\nКакой стиль общения предпочитаешь?',
    inputType: 'buttons',
    options: [
      { label: '😊 Дружелюбный', value: 'friendly', description: 'Как с коллегой, неформально' },
      { label: '💼 Деловой', value: 'formal', description: 'Чётко и по делу' },
      { label: '🎓 Экспертный', value: 'expert', description: 'Подробно и профессионально' }
    ],
    nextStep: 'specialization'
  },
  {
    id: 'specialization',
    message: '{styleConfirmation}\n\nЕсть ли узкая специализация для этого агента?',
    inputType: 'text-optional',
    placeholder: 'SMM и контент-маркетинг',
    hint: 'Например: "B2B продажи", "IT-стартапы"',
    nextStep: 'confirm'
  },
  {
    id: 'confirm',
    message: 'Готово! 🎉\n\nСоздаю "{name}":\n\n📋 Настройки:\n• Стиль: {style}\n{specialization}\n\nВсё верно?',
    inputType: 'buttons',
    options: [
      { label: '← Изменить', value: 'edit' },
      { label: '✓ Создать агента', value: 'create' }
    ],
    nextStep: 'done'
  }
];
```

### Сохранение в БД

После подтверждения создаётся запись в `user_agents`:

```typescript
{
  userId: currentUser.id,
  sourceAgentId: selectedAgent.id,
  name: "Мой маркетолог",
  customizations: {
    communicationStyle: "formal",      // friendly | formal | expert
    specialization: "SMM и контент-маркетинг"  // опционально
  },
  isActive: true
}
```

**Примечание:** Поля `userAddress` и `userContext` убраны — они берутся из профиля пользователя.

### Применение настроек к промпту

При запросе к AI с персональным агентом:

```typescript
function buildPrompt(agent: Agent, user: User, userAgent?: UserAgent): string {
  // Сначала данные из профиля пользователя
  const userContext = `
# Информация о пользователе

- Имя: ${user.displayName || user.name}
- Обращение: на "${user.pronouns || 'вы'}"
${user.occupation ? `- Сфера: ${user.occupation}` : ''}
${user.bio ? `- Контекст: ${user.bio}` : ''}

`;

  // Потом настройки персонального агента (если есть)
  let agentCustomization = '';
  if (userAgent?.customizations) {
    const c = userAgent.customizations;
    agentCustomization = `
# Персонализация агента

- Стиль общения: ${getStyleDescription(c.communicationStyle)}
${c.specialization ? `- Специализация: ${c.specialization}` : ''}

`;
  }
  
  return userContext + agentCustomization + agent.systemPrompt;
}
```

## 🔧 API endpoints

**POST /api/user-agents**
- Создание персонального агента
- Body: `{ sourceAgentId, name, customizations }`

**PATCH /api/user-agents/:id**
- Обновление персонального агента
- Body: `{ name?, customizations? }`

**DELETE /api/user-agents/:id**
- Удаление персонального агента
- Soft delete (isActive = false) или hard delete — на усмотрение

**GET /api/user-agents**
- Список персональных агентов пользователя
- Уже существует из ТЗ-1

## 📎 Сценарии для тестирования

### Сценарий 1: Создание персонального агента

```
1. Убедиться что профиль заполнен (имя, обращение)
2. Открыть страницу /agents/marketer
3. Нажать "В мои агенты"
4. Пройти диалог (4 шага)
5. Подтвердить создание
6. Проверить что агент появился в sidebar
7. Начать чат — проверить что использует данные из профиля
```

### Сценарий 2: Пропуск специализации

```
1. Начать создание персонального агента
2. Указать имя
3. Выбрать стиль
4. Нажать "Пропустить" на специализации
5. Создать агента
6. Проверить что работает без специализации
```

### Сценарий 3: Редактирование

```
1. Навести на агента в sidebar
2. Открыть меню → Редактировать
3. Изменить стиль общения
4. Сохранить
5. Начать чат — проверить что стиль изменился
```

### Сценарий 4: Профиль + персонализация агента

```
1. В профиле указать: имя "Владимир", обращение "вы"
2. Создать персонального агента со стилем "Дружелюбный"
3. Начать чат
4. Агент должен обращаться на "вы" к "Владимиру" 
   в дружелюбном стиле
```
