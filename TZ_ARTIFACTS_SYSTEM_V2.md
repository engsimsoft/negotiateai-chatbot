## 1. ИДЕЯ

**Целевая аудитория:** Юлия (маркетолог), не программист.

## 2. КОНТЕКСТ

### Текущая ситуация

Сейчас есть три типа артефактов:
- **text** — текст с Markdown разметкой
- **code** — Python/JS код + HTML презентации
- **sheet** — CSV таблицы

### Проблемы

1. **code и sheet не используются** — Владимир пишет код в VS Code, не в чате
2. **Markdown бесполезен** — Юлия копирует текст в соцсети, символы `## ** -` превращаются в мусор
3. **HTML презентации некрасивые** — генерируется голый HTML без дизайна, "стыдно показать"
4. **Нет шаринга** — кнопка "Open" создаёт blob: URL который нельзя отправить другому человеку

### Что нужно

Приложение для **непрограммистов**:
- Копирайтинг — чистый текст с эмодзи для соцсетей
- Презентации — профессиональный результат с wow-эффектом
- Шаринг — отправить ссылку в Telegram, получатель открывает без регистрации

## 4. ТРЕБОВАНИЯ

### 4.1 Удаление старых артефактов

**Удалить полностью:**
- Артефакт `code` (Python, JS, HTML)
- Артефакт `sheet` (CSV таблицы)
- Все связанные компоненты, handlers, UI элементы

**База данных:**
- Существующие артефакты code/sheet в БД можно оставить (не ломать историю)
- Новые создаваться не должны

### 4.2 Text артефакт — упрощение

**Формат:** Чистый plain text + эмодзи. Без Markdown разметки.

**Промпт агента должен:**
- Использовать эмодзи вместо буллетов (✅ • → 📌 🔹 вместо `- * 1.`)
- Использовать пустые строки для разделения вместо `##` заголовков
- Писать текст который идеально копируется в VK/Telegram/Instagram

**UI:**
- Отображать как plain text (не рендерить Markdown)
- Кнопка "Copy" — копировать в буфер
- Кнопка "Download" — скачать как .txt файл
- Убрать всё лишнее (AI suggestions, сложное форматирование)

### 4.3 Presentation-PPTX — новый артефакт

**Идея:** Создавать настоящие .pptx файлы профессионального качества.

**Технология:** PptxGenJS или аналог (Claude Code решает).

**Результат:**
- Файл открывается в PowerPoint, Google Slides, Keynote
- Юлия может редактировать после генерации
- Профессиональный дизайн: цветовые палитры, шрифты, иконки

**Система тем:**
- Набор готовых профессиональных тем (цвета + шрифты)
- Агент может предложить тему под контент
- Или пользователь выбирает сам

**UI:**
- Preview слайдов (конвертация в изображения)
- Кнопка "Download" — скачать .pptx
- Кнопка "Share" — публичная ссылка

**Качество:**
- Не "голые буллеты на белом фоне"
- Визуальные элементы: иконки, формы, цветовые акценты
- Разнообразие layouts между слайдами
- Читаемая типографика

### 4.4 Presentation-Reveal — новый артефакт

**Идея:** Wow-презентации в браузере для демонстрации идей.

**Технология:** Reveal.js — профессиональный фреймворк для HTML-презентаций.

**Возможности Reveal.js:**
- Красивые переходы между слайдами
- Keyboard навигация (стрелки)
- Fullscreen режим
- Speaker notes
- Экспорт в PDF
- Темы и плагины

**Дизайн:**
- Современные Google Fonts
- Продуманные цветовые палитры
- Анимации и эффекты
- Адаптивность

**UI:**
- Preview в iframe внутри артефакта
- Кнопка "Fullscreen" — на весь экран
- Кнопка "Share" — публичная ссылка
- Опционально: "Download PDF"

**Качество:**
- Уровень Gamma.app / Beautiful.ai
- Не стыдно показать клиенту
- Wow-эффект

### 4.5 Public Share — публичные ссылки

**Идея:** Любой артефакт можно расшарить по ссылке без авторизации.

**Как работает:**
1. Пользователь нажимает "Share" на артефакте
2. Система генерирует уникальный токен
3. Пользователь получает ссылку: `https://site.app/share/[token]`
4. Любой с ссылкой может открыть (без логина)
5. Видит ТОЛЬКО артефакт (не историю чата, не промпты)

**Для разных типов артефактов:**

| Артефакт | Что видит получатель |
|----------|---------------------|
| text | Текст + кнопка "Copy" |
| presentation-reveal | Fullscreen Reveal.js презентация |
| presentation-pptx | Preview слайдов + кнопка "Скачать .pptx" |

**Безопасность:**
- Токены уникальные (nanoid или UUID)
- Проверка владения при создании share
- Возможность отозвать доступ (unshare)
- noindex meta tags (не индексируется поисковиками)

**Приватность:**
- Получатель видит ТОЛЬКО артефакт
- История чата скрыта
- Промпты пользователя скрыты
- Имя автора можно скрыть

## 5. ОГРАНИЧЕНИЯ

### Технические
- Приложение уже на Next.js 15 + Vercel
- БД: PostgreSQL (Neon) + Drizzle ORM
- Файлы: Vercel Blob Storage
- AI: Google Gemini (можно использовать для генерации контента презентаций)

### Что НЕ нужно
- Редактирование презентаций в браузере (Юлия редактирует в PowerPoint)
- Совместная работа над артефактами
- Версионирование артефактов
- Комментарии к артефактам

### Совместимость
- Существующие text артефакты в БД должны продолжать открываться
- Существующие code/sheet артефакты — можно игнорировать (не ломать, но новые не создавать)
