## 🎯 Что это

**Simply** — платформа AI-агентов для российского рынка. Шлюз к лучшим мировым AI-моделям (GPT, Claude, Gemini) и best-in-class API сервисам с оплатой в рублях, без VPN.

**Философия:** Apple-подход. Лучше 10 идеально работающих агентов, чем 100 посредственных. Качество важнее экономии.

**Ключевой принцип инструментов:** Не изобретаем велосипеды. Интегрируем лучшие готовые решения (Perplexity для research, Plus AI для презентаций, Ideogram для изображений). Пользователь описывает задачу — получает iPhone-качество результат.

**Кто:** Бизнес-пользователи в России без технического бэкграунда (40+).

**Профессии:** Маркетологи, юристы, HR, предприниматели, продажники, блогеры, консультанты.

## 🏗️ Архитектура агентов

### Два типа агентов

| Тип | Описание | Статус |
|-----|----------|--------|
| **Системный** | Встроенный, нельзя удалить | ✅ Реализован |
| **Каталог** | Проработанные нами, пользователь добавляет к себе | ✅ Реализован |

> **Примечание:** Персональные агенты (адаптированные пользователем) — backend готов, UI убран в рамках упрощения UX (ТЗ-4). Может вернуться в будущих версиях.

### Текущие агенты (в БД)

| Агент | Тип | Модель | Описание |
|-------|-----|--------|----------|
| **Помощник** | system | Gemini 3 Pro | Умный роутер, рекомендует агентов |
| **Prompt-агент** | catalog | Gemini 3 Pro | Улучшает запросы пользователя |
| **Универсальный** | catalog | Gemini 2.5 Flash | Быстрые ответы на всё |
| **Маркетолог** | catalog | Gemini 3 Pro | Стратегия, анализ, позиционирование |
| **Копирайтер** | catalog | Gemini 3 Pro | Тексты для соцсетей, реклама |
| **Переводчик** | catalog | Gemini 3 Pro | Перевод с контекстом |
| **Наставник** | catalog | Gemini 3 Pro | Обучение, менторство |
| **Презентатор** | catalog | Gemini 3 Pro | PPTX и веб-презентации |

### @-mentions (гостевой вызов)

Пользователь может вызвать любого агента через @упоминание в любом чате. Агент отвечает один раз как "гость", не меняя основного агента чата.

```
Пользователь: @Переводчик переведи это на английский
Переводчик: [отвечает как гость]
[следующее сообщение идёт основному агенту чата]
```

## ⭐ Killer Feature: Утренний брифинг

**После Фазы 3**

Персональный AI-ассистент, который:
1. Каждое утро собирает информацию из источников пользователя (сайты, Telegram, Email)
2. Анализирует, фильтрует, структурирует
3. Превращает в 5-15 минутный аудио-дайджест
4. Отправляет в Telegram до начала рабочего дня

**Экономика:**
- Себестоимость: ~$0.44/брифинг
- Экономия для пользователя: ~1 час/день

## 🧠 Smart Routing (умный выбор модели)

Система автоматически выбирает оптимальную модель для экономии без потери качества.

| **Максимум качества** | Всегда лучшие модели |

6. **Pay-as-you-go** — платишь только за использованное
