## 🎯 Что это

**Simply** — платформа AI-агентов для российского рынка. Шлюз к лучшим мировым AI-моделям (GPT, Claude, Gemini) с оплатой в рублях, без VPN, с фокусом на качество а не количество.

**Философия:** Apple-подход. Лучше 10 идеально работающих агентов, чем 100 посредственных.

---

## 👥 Целевая аудитория

**Кто:** Бизнес-пользователи в России без технического бэкграунда.

| Сегмент | Боль | Решение |
|---------|------|---------|
| Нет доступа к ChatGPT/Claude | Санкции, нет карт Visa/MC | Оплата в рублях (ЮKassa, Тинькофф) |
| Не программисты | Не могут настроить API | Готовая платформа с UI |
| Нужны конкретные инструменты | Общие чат-боты не решают задачи | Специализированные агенты с инструментами |

**Профессии:** Маркетологи, юристы, HR, предприниматели, продажники.

## 🏗️ Архитектура агентов

### Три типа агентов

| Тип | Описание | Пример |
|-----|----------|--------|
| **Системный** | Встроенный, нельзя удалить | Агент-Помощник |
| **Каталог** | Проработанные нами, пользователь добавляет к себе | Маркетолог, Юрист, Аналитик сайтов |
| **Персональные** | Адаптированные пользователем версии из каталога | "Мой Юрист по аренде" |

### Агент-Помощник (системный)

**Роль:** Умный роутер + помощник по персонализации. НЕ создаёт агентов с нуля.

**Что делает:**
- Понимает задачу пользователя
- Рекомендует подходящего агента из каталога
- Помогает персонализировать агента под себя
- Отвечает на вопросы о платформе

**Пример диалога:**
```
Пользователь: "Мне нужно анализировать договоры аренды"

Агент-Помощник: "Для этого подойдёт агент Юрист. 
Он умеет анализировать договоры, находить риски, сравнивать версии.

Хотите использовать как есть или настроить под себя?"

→ [Использовать] [Настроить]
```

### Персонализация (не создание с нуля!)

**Что можно настроить:**

| Параметр | Пример |
|----------|--------|
| Имя агента | "Мой юрист Виктор" |
| Стиль общения | Формальный / Дружеский / Краткий |
| Обращение | На "ты" / На "вы" / По имени |
| Специализация | "Договоры аренды" / "IT-контракты" |
| Контекст | "Я ИП в Москве" / "Работаю в B2B" |

**Ключевое:** Пользователь НЕ пишет промпты. Он отвечает на простые вопросы, а качественная база уже сделана нами.

## 🧠 Smart Routing (умный выбор модели)

### Концепция

Система автоматически выбирает оптимальную модель для экономии без потери качества.

| Сложность | Модель | Цена |
|-----------|--------|------|
| Простой вопрос, чат | Gemini Flash / GPT-4o-mini | ~$0.10/1M токенов |
| Средняя задача | Gemini Pro / GPT-4o | ~$2-5/1M |
| Сложный анализ | Claude Sonnet | ~$3-15/1M |
| Максимум качества | Claude Opus / o1 | ~$15-60/1M |

### Режимы для пользователя

| Режим | Описание |
|-------|----------|
| **Авто (по умолчанию)** | Система сама выбирает модель |
| **Экономный** | Всегда дешёвые модели |
| **Максимум качества** | Всегда лучшие модели |
| **Ручной выбор** | Пользователь указывает модель |

### Мультипровайдер

Один API-ключ владельца → доступ ко всем моделям для пользователей:
- OpenAI (GPT-4o, GPT-4o-mini, o1)
- Anthropic (Claude Sonnet, Opus)
- Google (Gemini Pro, Flash)
- Возможно: OpenRouter как единый шлюз

## ⚡ Tool Activity UX

### Проблема

Сейчас: "thinking" показывается 3 секунды и пропадает. Пользователь не понимает — работает или зависло.

### Решение

Живая индикация в реальном времени какой инструмент работает.

**Пример:**
```
Пользователь: "Проанализируй сайт competitor.com"

[Анимация] 🌐 Загружаю страницу...
[Анимация] 📸 Делаю скриншот...
[Анимация] 👁️ Анализирую дизайн...
[Анимация] ⚡ Проверяю скорость...
[Анимация] 📊 Формирую отчёт...

→ Появляется ответ
```

**Маппинг инструментов:**
```
webSearch → "🔍 Ищу в интернете..."
fetchWebsite → "🌐 Загружаю страницу..."
screenshotWebsite → "📸 Делаю скриншот..."
analyzeSEO → "⚡ Анализирую SEO..."
transcribeAudio → "🎧 Транскрибирую аудио..."
generateImage → "🎨 Генерирую изображение..."
(fallback) → "🤔 Обрабатываю..."
```

## ✅ Ключевые принципы

1. **Apple, не Windows** — качество важнее количества
2. **Персонализация, не создание** — адаптируем готовое, не строим с нуля

4. **Smart by default** — умный выбор модели автоматически
5. **Русский рынок** — рубли, русский язык, понятный UX
