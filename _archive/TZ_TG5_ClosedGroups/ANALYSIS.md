# Анализ ТЗ-TG5: Чтение закрытых групп через бота

## Резюме

Расширить @GetSimplyBot для работы в Telegram-группах: бот, добавленный в закрытую группу, сохраняет текстовые сообщения в PostgreSQL. Данные отображаются в отдельной странице `/groups` в дашборде. Подготовка к будущему AI-анализу (TG6) и RAG (TG9).

### Согласен с ТЗ

- Схема БД (3 таблицы) — логичная, соответствует паттернам проекта (uuid PK, timestamps, FK → User)

### Согласовано: изменения относительно ТЗ

| # | Было (ТЗ) | Решение | Обоснование |

### Ручное действие (вне кода)

- **Privacy Mode бота:** Необходимо отключить через @BotFather → `/setprivacy` → Disabled. Без этого бот видит только команды и @mentions в группах. Claude Code не может сделать это программно.

## Потенциальные риски

1. **Privacy Mode не отключён** — бот не получит сообщения из групп. Митигация: проверка в тестовом сценарии.
2. **Большой объём сообщений в активных группах** — INSERT per message при 100+ msg/min может замедлить webhook response. Митигация: мониторинг, batch в будущем если нужно.
3. **Telegram rate limits на webhook response** — webhook должен отвечать за < 60 секунд. Митигация: INSERT в БД быстрый (< 50ms), без тяжёлых операций.
