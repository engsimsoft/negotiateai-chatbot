# Dev Mode — обновлённый промпт-блок

**Файл в коде:** `lib/prompts/core/dev-mode.md`  
**Заменяет:** текущий dev-mode.md  
**Активируется:** `SIMPLY_DEV_MODE=true` в `.env.local`

---

## Промпт

```xml
<dev_mode>
РЕЖИМ РАЗРАБОТКИ АКТИВЕН. Это обязательное требование, не рекомендация.

Формат КАЖДОГО ответа без исключений:

[DEV] Режим: [значение из <current_mode>: chat / expertise / create]
Модель: [твоя модель: Haiku / Sonnet / Opus]
Роль: [Simply Chat / Экспертиза / Создать / Менеджер / Эксперт]
Триггеры: [что сработало — навигация на Экспертизу/Создать/Проекты, tool call, отказ, ничего]
Формат: [почему выбрал такой формат ответа]
---

[основной ответ]

Самопроверка: если ты начал писать ответ без блока [DEV] — остановись и добавь его.
</dev_mode>
```

---

## Что изменилось по сравнению с предыдущей версией

1. **Добавлена строка «Режим»** — значение из `<current_mode>`. Решает конкретный баг: при тестировании маршрутизации невозможно определить в каком режиме находишься.

2. **Добавлена строка «Модель»** — дублирует бейдж модели в тексте. Полезно когда бейдж не виден или при копировании логов.

3. **Шаблон вместо описания** — модель видит точный формат, а не абстрактную инструкцию «кратко объясни». Снижает вариативность.

4. **Самопроверка (self-check)** — фраза «если начал без [DEV] — остановись и добавь». Приём, проверенный на Claude — реально снижает пропуски.

5. **Жёсткая формулировка** — «обязательное требование, не рекомендация» вместо мягкого «перед каждым ответом кратко объясни».

## Dev-reminder (дополнительная мера для длинных диалогов)

**Проблема:** В длинных диалогах (15+ сообщений), особенно в проектах с большим контекстом, модель может «забыть» dev_mode инструкцию из начала промпта.

**Решение:** Добавлять короткое напоминание в конец собираемого промпта, ближе к ответу.

**Для архитектора — в `composer.ts` (и аналогично в проектных composers):**

```typescript
// В самом конце сборки промпта, последний блок перед return:
if (process.env.SIMPLY_DEV_MODE === 'true') {
  parts.push('<dev_reminder>DEV-РЕЖИМ: каждый ответ НАЧИНАЕТСЯ с блока [DEV]. Режим: ' + chatMode + '</dev_reminder>');
}
```

Это напоминание весит ~20 токенов, но находится максимально близко к ответу модели — поэтому работает надёжнее чем инструкция в начале промпта.
