**Версия:** 1.0
**Дата:** 2026-02-03
**Базовая версия проекта:** 3.3.3

## Цель проекта

Перестроить интерфейс Simply: новая Главная страница, линейная навигация, контекстный sidebar без табов, и Universal Dialog Component для создания проектов через диалог с AI.

**Результат:** пользователь открывает Simply → видит Главную с полем ввода → начинает печатать и попадает в чат → или кликает на проект/помощника → внутри видит sidebar с чатами текущего контекста.

## Git-практики (ОБЯЗАТЕЛЬНО)

**Принцип:** Каждый этап = отдельная ветка → PR → merge в master после валидации.

### Naming convention
```
feature/tz07a-01-database-schema
feature/tz07a-02-helpers-presets
feature/tz07a-03-navigation-routes
feature/tz07a-04-sidebar
feature/tz07a-05-glavnaya
feature/tz07a-06-autonaming
feature/tz07a-07-universal-dialog
feature/tz07a-08-final-testing
```

### Workflow для каждого этапа
1. `git checkout master && git pull`
2. `git checkout -b feature/tz07a-XX-название`
3. Выполнить задачи этапа
4. Пройти валидацию этапа
5. `git add . && git commit -m "feat(tz07a): описание"`
6. `git push -u origin feature/tz07a-XX-название`
7. Создать PR в master
8. После ревью: merge и удалить ветку

### Точки отката
При критических проблемах можно откатиться к последнему стабильному коммиту:
```bash
git log --oneline -10           # найти хороший коммит
git checkout <commit-hash>      # временный откат для проверки
git revert <commit-hash>        # отменить конкретный коммит
```

### Коммиты внутри этапа
Делать промежуточные коммиты после каждой крупной задачи:
```
feat(db): add Helper table to schema
feat(db): add helperId and isRenamed to Chat
feat(db): add CRUD queries for Helper
```
