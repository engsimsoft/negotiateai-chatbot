## Принятые решения

### 1. Главная (бывший Dashboard)

Название экрана: **"Главная"** — понятно любому пользователю, стандарт для русскоязычной аудитории.

**Структура сверху вниз (иерархия внимания):**

```
ГЛАВНАЯ
├── Приветствие + поле ввода     ← вход в универсальный чат (Gemini)
├── ПРОЕКТЫ                      ← карточки проектов + "Новый проект"
├── ПОМОЩНИКИ                    ← кастомные → предустановленные → Конструктор
└── ИНСТРУМЕНТЫ                  ← Диктофон, Исследование, Брифинг
```

**Ключевое решение: поле ввода на Главной.** Начал печатать → Enter → переход в полноценный чат с Gemini, текст уже как первое сообщение. Один шаг вместо двух. Это убирает карточку "💬 Чат" как отдельный элемент — поле ввода и есть вход в чат.

**Помощники на Главной:**
- Кастомные помощники отображаются выше предустановленных (важнее для вернувшегося пользователя)
- Предустановленные: Маркетолог, Копирайтер, Переводчик, Аналитик, Наставник + ещё 3-4
- Конструктор — создаёт кастомных помощников
- Кастомные помечаются тегом "свой"

**Создан интерактивный прототип** (`simply-glavnaya-wireframe.jsx`).

### 2. Помощник = вход в чат с предустановкой

Помощник — не отдельная сущность и не "комната". Это **чат с предустановленным промптом и навыками**. Стандартный паттерн как GPTs.

- У помощника есть список его чатов
- Можно начать новый чат
- В каждом чате можно загружать файлы
- Пользователю не нужно понимать разницу между "чатом" и "помощником"

### 3. Навигационная модель

**Линейная цепочка, каждый экран знает одного родителя:**

```
Главная
├── Чат (Gemini)               ← печатаешь на Главной
├── Проект → Чат (Claude)      ← два уровня вглубь
├── Помощник → Чат (Gemini)    ← два уровня вглубь
└── Инструменты                ← каждый своё
```

**Правило:** каждый экран имеет кнопку "← Назад" к родителю + breadcrumbs для полного пути. `← Главная / 📊 Стратегия 2026 / Анализ конкурентов` — клик на любую часть ведёт на тот уровень.

### 4. Sidebar — только в рабочих пространствах, без табов

| Решение | Было | Стало |
|---|---|---|
| Sidebar на Главной | Нет | Нет (подтверждаем) |
| Sidebar в чатах/проектах/помощниках | Да, с 3 табами (Search, Chats, Projects) | Да, **без табов** |
| Содержимое sidebar | Общий список всех чатов | **Чаты текущего контекста** |
| Search таб | Был, не работал | Убираем. Позже — поиск внутри списка |

**Контекстный sidebar:**

| Где ты | Sidebar показывает |
|---|---|
| Универсальный чат | Общие чаты (Gemini) |
| Чат в проекте | Чаты этого проекта (Claude) |
| Чат с помощником | Чаты этого помощника |

Один компонент, одно поведение — меняется только содержимое. Сверху — кнопка "+ Новый чат".

### 5. Layout страницы проекта — двухколоночный

**Поле ввода сверху** — тот же паттерн что на Главной. Печатаешь → попадаешь в чат проекта (Claude). Выбор модели (⚡🎯🎓) прямо в поле ввода.

**Двухколоночный layout:**
- **Левая колонка:** Паспорт проекта (табы Паспорт/Инструкция) + Файлы (список + drag & drop)
- **Правая колонка:** Чаты проекта (список + кнопка "Новый чат")

**Навигация:** `← Главная / 📊 Стратегия 2026`. Кнопка "⚙️ Настроить" в header — вход в Universal Dialog для редактирования проекта.

**Мета-информация внизу:** дата создания, модель по умолчанию, количество чатов и файлов.

**Создан интерактивный прототип** (`simply-project-page.jsx`).

### 6. Превью файлов — конкурентное преимущество

**Принцип:** Любой файл в проекте кликабелен. Поддерживаемые форматы открываются в существующем холсте (canvas), неподдерживаемые — кнопка "Скачать".

**Критичная функция.** Ни Claude, ни ChatGPT не дают нормально просматривать загруженные файлы внутри проекта. Это реальная боль даже для опытных пользователей.

**Движки для рендеринга уже есть** (артефакты):
- ✅ Excel (ExcelJS)
- ✅ Презентации (Reveal.js, PptxGenJS)
- ✅ Text, Markdown
- ✅ PDF Export (jsPDF, нужен pdf.js для просмотра)
- ✅ Изображения (нативно)
- ❌ Word (.docx) — не делаем

**Архитектурное решение:** клик по файлу → открывается тот же canvas, который используется для артефактов. Не изобретаем новый viewer.

### 7. Управление чатами

**Удаление и переименование:** иконка "⋯" на чате → меню "Переименовать" / "Удалить". Удаление с подтверждением.

**Автонейминг чатов:**

| Момент | Название |
|---|---|
| Чат создан | "Новый чат" |
| После 2-3 обменов | AI генерирует название по теме разговора (не по первому сообщению) |
| Пользователь переименовал | Его название навсегда, автонейминг отключается |

Модель для нейминга — Gemini Flash или Haiku (дешёвая операция). Инструкция: "2-4 слова, суть задачи, без глаголов. Пример: 'Анализ конкурентов', 'Бюджет Q1'."

## Ключевые идеи

- **Один паттерн ввода:** поле на Главной и на странице проекта работает одинаково — печатаешь и попадаешь в чат. Пользователь выучивает один раз
- **Контекстный sidebar** вместо табов — интерфейс сам знает что показывать, пользователю не нужно переключать
- **Превью файлов через существующий canvas** — минимум новой разработки, максимум пользы. Конкурентное преимущество перед Claude/ChatGPT
- **Помощники не усложняют навигацию** — это просто чат с предустановкой, тот же паттерн что везде
- **Три секции на Главной вместо четырёх** — поле ввода заменило карточку "Чат"

## Критический анализ (выявленные риски)

| Риск | Описание | Митигация |
|---|---|---|
| **Превью файлов — scope creep** | Подключение всех форматов к canvas может разрастись | Начать с изображений и PDF, расширять итерационно |
| **Автонейминг — стоимость** | Каждый чат после 2-3 обменов вызывает модель | Gemini Flash/Haiku — дёшево. Можно батчить |
| **Двухколоночный layout на мобильных** | Две колонки не влезут | Схлопывать в одну колонку. Отложено, не MVP-приоритет |
| **Поле ввода на Главной — неочевидность** | Пользователь может не понять что это вход в чат | Placeholder "Спросите что угодно..." + подсказка Бена для новичков |

## Отклонённые варианты

| Вариант | Почему отклонён |
|---|---|
| "Dashboard" как название | Англицизм, непонятен аудитории 40-60+ |
| "Консоль" как название | Ассоциации с играми/терминалом |
| "Рабочий стол" | Длинно для навигации |
| Помощник как отдельная сущность со своим экраном | Третий тип пространства, усложняет навигацию |
| Sidebar с табами (Search, Chats, Projects) | Избыточно при хорошей структуре хранения чатов |
| Search как отдельный таб | Не нужен при контекстном sidebar. Позже — поиск внутри списка |
| Карточка "💬 Чат" на Главной | Поле ввода заменяет её полностью |
| Превью Word (.docx) | Плохое качество рендеринга, не стоит усилий |
