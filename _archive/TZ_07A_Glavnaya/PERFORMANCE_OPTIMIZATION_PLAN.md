## Выявленные проблемы

### 1. Дублирующиеся API запросы

**Симптом:**
```
GET /api/user/ben-intro 200 in 454ms
GET /api/user/ben-intro 200 in 446ms  ← дублирование!

GET /api/deepgram/token 200 in 18ms
GET /api/deepgram/token 200 in 7ms    ← дублирование!
```

**Причина:** Компоненты вызывают одни и те же API несколько раз (возможно из-за React StrictMode или неправильной структуры хуков).

**Решение:**
- [ ] Найти места вызова `/api/user/ben-intro`
- [ ] Найти места вызова `/api/deepgram/token`
- [ ] Использовать SWR кеширование для предотвращения дублирования
- [ ] Проверить useEffect зависимости

---

### 2. Медленные запросы к базе данных

**Симптом:**
```
GET /api/vote 200 in 900ms
GET /api/user/ben-intro 200 in 4486ms
GET /api/projects 200 in 4775ms
```

**Причина:** Удалённая база данных Neon + отсутствие кеширования.

**Решение:**
- [ ] Добавить индексы в базу данных (если отсутствуют)
- [ ] Использовать `unstable_cache` для редко меняющихся данных
- [ ] Рассмотреть Redis кеширование для частых запросов

---

### 3. Компиляция в Development Mode

**Симптом:**
```
✓ Compiled /chat/[id] in 1289ms (13126 modules)
✓ Compiled /api/helpers in 543ms (7539 modules)
```

**Причина:** Next.js компилирует код при первом обращении к странице.

**Решение:**
- Это нормально для development
- В production (после `npm run build`) компиляция не происходит
- **Действий не требуется**
