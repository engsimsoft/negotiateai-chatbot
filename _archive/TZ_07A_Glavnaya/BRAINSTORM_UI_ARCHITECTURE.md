## Что это за проект

Simply — AI-платформа для российского рынка. Два основных режима:
1. **Универсальный чат** (Gemini) — с инструментами, артефактами
2. **Проекты** (Claude) — изолированные рабочие пространства

---

## Текущая структура маршрутов

```
/dashboard          → Точка входа, карточки инструментов (БЕЗ sidebar)
/settings           → Настройки пользователя (БЕЗ sidebar)

/chat               → Новый чат (С sidebar)
/chat/[id]          → Существующий чат (С sidebar)

/projects           → Список проектов (БЕЗ sidebar, в dashboard layout)
/projects/[id]      → Страница проекта (БЕЗ sidebar)
/projects/[id]/chat → Чат в проекте (С sidebar)
```

**Проблема:** Непоследовательность — projects находится и в dashboard layout (список, страница проекта), и в chat layout (чат проекта).

---

## Два layout-а

### Dashboard Layout (без sidebar)
- Простой, центрированный контент
- Используется для: `/dashboard`, `/settings`, `/projects`, `/projects/[id]`

### Chat Layout (с sidebar)
- Sidebar слева с табами и историей
- Используется для: `/chat/*`, `/projects/[id]/chat/*`

## Chat Interface

```
┌─────────────────────────────────────────────────────────────┐
│  HEADER: [Toggle] Breadcrumbs...   [📝 Prompt] [❓ Ben] [+] │
├─────────────────────────────┬───────────────────────────────┤
│                             │                                │
│      MESSAGES               │      ARTIFACT/CANVAS           │
│      (scrollable)           │      (документ справа)        │
│                             │                                │
│  User: ...                  │  ┌─────────────────────────┐  │
│  AI: ...                    │  │  Markdown / Excel /     │  │
│                             │  │  Presentation / Text    │  │
│                             │  └─────────────────────────┘  │
│                             │                                │
├─────────────────────────────┴───────────────────────────────┤
│  INPUT: [Model ▼] [Textarea...] [🎤] [📎] [Send]           │
└─────────────────────────────────────────────────────────────┘
```

**Левая панель:** `messages.tsx`, `message.tsx`
**Правая панель:** `artifact.tsx` (появляется при создании документа)
**Низ:** `multimodal-input.tsx`, `prompt-input.tsx`, `voice-button.tsx`

## Артефакты (Canvas)

5 типов документов:
| Тип | Описание |
|-----|----------|
| `text` | Plain text для соцсетей |
| `markdown` | Форматированные документы |
| `excel` | Таблицы с формулами и графиками |
| `presentation-reveal` | Веб-презентации |
| `presentation-pptx` | PowerPoint |

Артефакт появляется справа при создании документа через tool call.

## Текущие боли (для обсуждения)

1. **Непоследовательность layout-ов** — projects то с sidebar, то без
2. **Dashboard слишком простой** — две карточки и всё
3. **Переход между режимами** — не всегда очевидно где находишься
4. **Sidebar tabs** — Search таб пока не функционален
5. **Навигация в проектах** — breadcrumbs работают, но UX можно улучшить
