## Цель

Клик по файлу в проекте → полноэкранная модалка (lightbox) с превью содержимого. Посмотрел → закрыл → ты там же где был. Ни Claude, ни ChatGPT не дают нормально просматривать файлы внутри проекта — это конкурентное преимущество Simply.

**Результат:** пользователь кликает на любой файл в проекте → открывается оверлей с содержимым файла или понятной заглушкой с кнопкой "Скачать".

## Часть 1. Компонент FileViewer

### Архитектура

Автономный компонент, не зависящий от Chat или Artifact. Вызывается откуда угодно: страница проекта, список файлов, в будущем — результаты поиска.

```typescript
interface FileViewerProps {
  file: {
    name: string;
    url: string;
    contentType: string; // mimeType
    metadata?: { extractedContent?: string };
  };
  // Навигация между файлами (опционально):
  files?: Array<{ name: string; url: string; contentType: string }>;
  currentIndex?: number;
  onClose: () => void;
  onNavigate?: (index: number) => void;
}
```

Пропсы `files`, `currentIndex`, `onNavigate` — для навигации стрелками между файлами в папке. Если не переданы — просто показывает один файл без стрелок.

### Layout модалки

```
┌──────────────────────────────────────────────────────┐
│  ✕       report.pdf                       ⬇ Скачать  │
│──────────────────────────────────────────────────────│
│                                                      │
│                                                      │
│              [содержимое файла]                       │
│              (рендерер по типу)                       │
│                                                      │
│                                                      │
│  ←                                                →  │
│                                                      │
└──────────────────────────────────────────────────────┘
   ↑ затемнённый backdrop (клик = закрытие)
```

**Header:** крестик закрытия (слева) + имя файла (центр) + кнопка "Скачать" (справа, прямая ссылка на file.url с атрибутом download).

**Стрелки навигации** (← →): появляются только если передан массив `files`. Полупрозрачные, по бокам контента. На мобильных — свайп.

### Три обязательных состояния

1. **Loading** — скелетон или спиннер по центру. Для изображений можно blur placeholder если доступен
2. **Success** — содержимое отрендерено
3. **Error / Unsupported** — иконка файла + текст "Этот формат нельзя просмотреть" + крупная кнопка "⬇ Скачать файл"

## Часть 2. Рендеринг по форматам

### Изображения (png, jpg, jpeg, gif, webp, svg)

```jsx
<img src={file.url} alt={file.name} style={{ objectFit: 'contain', maxWidth: '100%', maxHeight: '100%' }} />
```

- Fit-to-container, без обрезки
- Без zoom в первой итерации

### PDF

```jsx
<iframe src={file.url} title={file.name} style={{ width: '100%', height: '100%', border: 'none' }} />
```

- Браузер даёт навигацию по страницам, зум, скролл бесплатно
- Если iframe не загрузился — fallback на кнопку "Скачать"

### Текст (.txt)

- `fetch(file.url)` → отобразить в `<pre>` с моноширинным шрифтом
- Скролл если текст длинный
- Ограничение: если файл > 1MB, показать первые ~500KB + сообщение "Файл слишком большой для полного просмотра" + кнопка "Скачать"

### Markdown (.md)

- `fetch(file.url)` → отрендерить через существующий `MarkdownRenderer` (или аналогичный компонент, который уже используется для артефактов)
- Стилизация как в артефактах

### Excel (.xlsx, .xls, .csv)

Два варианта рендеринга, в зависимости от наличия данных:

**Вариант A (есть extractedContent):** Показать `metadata.extractedContent` в виде отформатированной таблицы. extractedContent обычно содержит текстовое представление данных — отобразить в `<table>` или `<pre>` с подсветкой структуры.

**Вариант B (нет extractedContent):** Показать иконку Excel + "Скачать для просмотра".

**CSV** — если файл .csv, можно fetch → распарсить → показать как `<table>`. Библиотека не нужна, CSV парсится тривиально (split по строкам и запятым, учитывая кавычки).

### Презентации (.pptx)

Аналогично Excel:

**Вариант A (есть extractedContent):** Показать extractedContent как форматированный текст — заголовки слайдов, содержимое. Не полноценный viewer, но пользователь видит что внутри.

**Вариант B (нет extractedContent):** Иконка + "Скачать для просмотра".

### Неподдерживаемые форматы (всё остальное)

Иконка типа файла (можно Lucide icon по расширению) + имя файла + размер (если доступен) + кнопка "⬇ Скачать файл". Никогда пустой экран.

## Часть 3. Клавиатура и доступность

Это не опционально — это обязательные требования.

### Клавиатура

| Клавиша | Действие |
|---------|----------|
| **Escape** | Закрыть модалку |
| **← стрелка влево** | Предыдущий файл (если есть files[]) |
| **→ стрелка вправо** | Следующий файл (если есть files[]) |

### Focus management

- При открытии: фокус переходит на кнопку закрытия (✕)
- **Focus trap**: Tab циклически ходит только по элементам внутри модалки (✕, Скачать, стрелки навигации)
- При закрытии: фокус возвращается на элемент, который открыл модалку

### ARIA

- `role="dialog"` на контейнере модалки
- `aria-modal="true"`
- `aria-label` с именем файла (например: `aria-label="Просмотр файла: report.pdf"`)

### Touch targets

Все кликабельные элементы — минимум 44×44px (WCAG 2.5.8). Особенно крестик и кнопка "Скачать".

## Часть 4. Интеграция со страницей проекта

### Где вызывается

На странице проекта файлы отображаются в левой колонке (секция "Файлы"). Клик по файлу → открывает FileViewer.

Передавать **все файлы текущей папки** (или корня) как массив `files` + индекс кликнутого файла. Это даёт навигацию стрелками между файлами.

### Клик по backdrop

Клик по затемнённому фону за пределами контента = закрытие модалки. Стандартный lightbox-паттерн.

### Анимация

Минимальная: fade-in backdrop (opacity 0→0.5) + scale-up контента (transform: scale 0.95→1). Длительность ~200ms. Придаёт ощущение "открылось поверх", а не "страница переключилась".

## Ограничения

### Обязательно

- Автономный компонент, не зависящий от Chat/Artifact
- Все три состояния (loading, success, error/unsupported)
- Escape закрывает, focus trap, return focus
- Рендеринг: изображения, PDF, текст, markdown, extractedContent для Excel/PPTX
- Graceful fallback для всех неподдерживаемых форматов (иконка + скачать)
- Клик по backdrop закрывает
- Стрелки навигации между файлами если передан массив

### На усмотрение Claude Code

- Определение типа файла (по contentType, по расширению, или комбинация)
- Конкретная реализация focus trap (свой код или библиотека)
- Формат отображения extractedContent (таблица, pre, markdown)
- Стиль скелетона загрузки
- Анимация появления/закрытия (fade + scale или другая)
- Мобильная адаптация (полноэкранный режим, свайп для закрытия)
- Парсинг CSV (split или библиотека)
- Иконки для неподдерживаемых форматов

### Не входит в это ТЗ

- Zoom/pan для изображений (позже)
- Полноценный рендеринг Excel через ExcelJS в модалке (позже)
- Полноценный рендеринг презентаций через Reveal.js в модалке (позже)
- Редактирование файлов из превью
- Превью файлов из чата (пока только со страницы проекта)

## Критерий готовности

- Клик по файлу на странице проекта → открывается lightbox
- Изображения отображаются (fit-to-container)
- PDF отображается (iframe с навигацией)
- Текстовые файлы отображаются (fetch → pre)
- Markdown рендерится через существующий компонент
- Excel/PPTX с extractedContent показывают содержимое
- Неподдерживаемые форматы — иконка + "Скачать"
- Escape закрывает модалку
- Стрелки ← → переключают файлы в папке
- Клик по фону закрывает
- Фокус управляется корректно (trap + return)
- Кнопка "Скачать" работает для всех форматов
