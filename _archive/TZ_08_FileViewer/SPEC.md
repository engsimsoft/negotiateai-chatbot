## Краткое описание

Lightbox-модалка для просмотра файлов проекта. Клик по файлу → полноэкранный оверлей с содержимым или fallback "Скачать".

## Поддерживаемые форматы

- **Изображения:** png, jpg, jpeg, gif, webp, svg
- **PDF:** встроенный просмотр через iframe
- **Текст:** .txt, .md, .csv
- **Office:** Excel/PPTX через extractedContent
- **Остальные:** fallback с кнопкой "Скачать"

## Ключевые требования

1. Автономный компонент (не зависит от Chat/Artifact)
2. Три состояния: Loading, Success, Error/Unsupported
3. Accessibility: focus trap, Escape, ARIA
4. Навигация стрелками между файлами
5. Кнопка "Скачать" для всех форматов
