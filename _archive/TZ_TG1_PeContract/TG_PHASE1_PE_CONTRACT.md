## Что нужно от PE

### 1. Новый skill: `telegram-channel-reading`

**Уровень:** B (skill для нового tool, по классификации SIMPLY_SKILLS_ARCHITECTURE.md)

**Парный tool:** `readTelegramChannel` — читает последние N постов публичного Telegram-канала и передаёт их AI в контекст. AI сам анализирует контент, tool только доставляет данные.

#### Что tool даёт AI на вход

```
channel: "omggpt"
channelUrl: "https://t.me/omggpt"
posts: [
  { text: "полный текст поста", date: "2026-02-25T10:00:00Z", url: "https://t.me/omggpt/1234", hasMedia: true },
  { text: "...", date: "...", url: "...", hasMedia: false },
  ...
]
totalFetched: 18
oldestDate: "2026-02-20T..."
newestDate: "2026-02-25T..."
```

#### Что skill должен описать

**Перед началом работы:**
- Какие уточняющие вопросы задать пользователю (или не задавать — решить)
- Как определить цель чтения: быстрый обзор vs глубокий анализ vs мониторинг

**Основные правила анализа:**
- Как структурировать выдачу по постам канала
- На что обращать внимание: темы, частота публикаций, стиль, форматы (текст/медиа), вовлечённость
- Как выделять ключевые тенденции
- Как цитировать — со ссылкой на конкретный пост

**Адаптация под режим:**

| Режим | Поведение |
|-------|-----------|
| **Экспертиза** | Аналитический: структура тем, частота, стиль, тренды. Точность и источники |
| **Создание** | Практический: что можно использовать, какие форматы работают, идеи для контента |
| **Проект** | Контекстный: привязка к задачам проекта, регулярный мониторинг, сравнение с данными проекта |

**Типы запросов пользователя (skill должен покрывать все):**
- "О чём последний пост в @channel?" — быстрый ответ, 2-3 предложения
- "Проанализируй канал @channel" — полный разбор: темы, стиль, частота, рекомендации
- "Сравни @channel1 и @channel2" — сравнительный анализ (два вызова tool)
- "Что писали про [тему] в @channel?" — поиск по контенту постов
- "Какой стиль у канала @channel?" — анализ tone of voice, форматов, приёмов

**RAG-секция (неактивна, но заложить):**
- С RAG: сравнение контента канала с базой знаний пользователя, поиск пересечений
- Без RAG: работа стандартно

**Российская адаптация:**
- Telegram — основная платформа для медиа в России, skill должен это учитывать
- Терминология: канал (не channel), подписчики, пост (не публикация)

**Самопроверка:**
- Чеклист перед отдачей результата пользователю

#### Формат

Стандартный SKILL.md по шаблону из SIMPLY_SKILLS_ARCHITECTURE.md (секция 6). Целевой размер: 80-150 строк.

#### Где будет лежать

`lib/prompts/skills/telegram-channel-reading/SKILL.md`
