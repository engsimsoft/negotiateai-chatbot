## Цель

Создать страницу управления общими чатами с AI-generated summary для каждого чата. Пользователь видит все свои общие чаты, понимает о чём каждый из них, и может быстро открыть нужный или удалить ненужный.

**Результат:** пользователь на Главной нажимает "💬 История чатов" → попадает на страницу со всеми общими чатами → слева список с названиями, справа краткое содержание выбранного чата → может открыть или удалить.

---

## Контекст

### Зачем это нужно
В 07A мы убрали sidebar с Главной — потерялся доступ к старым чатам. Карточка "💬 История чатов" на Главной решает вход, но нужна страница назначения.

### Проблема конкурентов
Claude: 191 чат в одном списке — общие и проектные вперемешку, без summary, невозможно разобраться. ChatGPT: аналогично.

### Преимущество Simply
Чаты **уже разделены** по контекстам (07A): общие, проектные, помощниковые. На странице `/chats` показываются **только общие чаты** (Gemini). Проектные — на странице проекта, помощниковые — у помощника. Проблема "191 чат в куче" не возникает.

## Часть 1. Карточка на Главной

В 07A на Главной уже есть карточка "💬 История чатов" слева от поля ввода (wireframe `simply-glavnaya-v2.jsx`). Она ведёт на `/chats`.

Карточка показывает:

Если общих чатов нет — карточку не показывать. Поле ввода занимает всю ширину.

## Часть 2. Страница `/chats`

### Layout — двухколоночный

```
← Главная / История чатов                        [+ Новый чат]
┌──────────────────────────┬──────────────────────────────────┐
│                          │                                   │
│  СПИСОК ЧАТОВ            │  СОДЕРЖАНИЕ ЧАТА                  │
│                          │                                   │
│  🔵 Анализ конкурентов   │  Название: Анализ конкурентов     │
│     Сегодня, 14:30       │                                   │
│                          │  О чём: Обсудили основных          │
│  ○ Бюджет Q1             │  конкурентов в сегменте B2B,      │
│    Вчера                 │  сравнили цены и позиционирование. │
│                          │  Составили таблицу сильных и       │
│  ○ Контент-план VK       │  слабых сторон.                   │
│    3 дня назад           │                                   │
│                          │  Дата: Сегодня, 14:30             │
│  ○ Стратегия маркетинга  │  Сообщений: 24                    │
│    5 дней назад          │                                   │
│                          │  [Открыть чат →]    [🗑️ Удалить] │
│                          │                                   │
└──────────────────────────┴──────────────────────────────────┘
```

### Левая колонка — список чатов
- Только **общие чаты** (без проектных, без помощниковых)
- Каждый чат: название (title) + дата последнего сообщения
- Сортировка: новые сверху
- Активный чат подсвечен
- При наведении — иконка удаления (🗑️) справа на строке
- Кнопка ⭐ на каждом чате — пометить как важный (для будущей индексации RAG)
- Помеченные чаты показывают ⭐ постоянно (не только при наведении)

### Правая колонка — детали выбранного чата
- Название чата
- Summary (1-2 предложения, сгенерированные AI)
- Дата и количество сообщений
- Кнопка "Открыть чат →" — переход в `/chat/[id]`
- Кнопка "Удалить" с подтверждением

### Если чат не выбран
Правая колонка показывает подсказку: "Выберите чат слева, чтобы увидеть краткое содержание"

### Если чатов нет
Вместо двухколоночного layout — центрированное сообщение: "У вас пока нет чатов. Начните первый разговор на Главной!" с кнопкой "← На Главную"

### Навигация
- Header: `← Главная / История чатов`
- Кнопка "+ Новый чат" в header → переход в `/chat` (новый чат)
- Sidebar на этой странице **отсутствует** (это не рабочее пространство, это менеджер)

## Часть 3. Расширение автонейминга

В 07A реализован автонейминг: после 2-3 обменов Gemini Flash генерирует `title`.

### Что добавить
В том же вызове генерировать **и title, и summary**. Один запрос — два результата.

### Инструкция для AI (расширенная)

```
Прочитай диалог. Верни JSON:
{
  "title": "короткое название, 2-4 слова, без глаголов",
  "summary": "о чём был разговор, 1-2 предложения, на русском"
}

Примеры:
{"title": "Анализ конкурентов", "summary": "Обсудили основных конкурентов в сегменте B2B, сравнили цены и позиционирование."}
{"title": "Бюджет Q1", "summary": "Рассчитали бюджет на первый квартал, распределили по каналам маркетинга."}
{"title": "Контент-план VK", "summary": "Составили план публикаций на месяц для группы ВКонтакте, определили рубрики."}
```

### Схема БД
Добавить в таблицу `Chat`:
- `summary` (text, nullable) — краткое содержание чата
- `isStarred` (boolean, default false) — важный чат, помечен пользователем для будущей индексации RAG

Поля `isRenamed` и `title` уже добавлены в 07A.

### Когда генерировать
- После получения **2-го ответа AI** (как и title)
- В фоне, не блокирует чат
- Если пользователь переименовал чат (`isRenamed = true`) — title больше не обновляется, но summary **всё равно генерируется** (переименование не отменяет summary)

### Для существующих чатов
Чаты созданные до внедрения summary — показывать без summary. В правой колонке вместо текста: "Краткое содержание будет доступно для новых чатов". Опционально: фоновая задача для генерации summary старых чатов (низкий приоритет).

## Часть 4. Удаление чатов

### Из списка на странице `/chats`
- Иконка 🗑️ при наведении на чат в списке
- Или кнопка "Удалить" в правой колонке
- Подтверждение: "Удалить чат «Анализ конкурентов»? Это действие нельзя отменить"
- После удаления: чат исчезает из списка, выделение переходит на следующий

### Из sidebar (уже в 07A)
Меню ⋯ → "Удалить" с подтверждением. Та же логика.
Меню ⋯ → "⭐ Важный чат" / "Убрать из важных" — переключение `isStarred`.

## Ограничения и требования

### Обязательно
- На странице `/chats` показывать **только общие чаты** (без проектных и помощниковых)
- Summary генерируется в том же вызове что и title — не создавать отдельный запрос
- Двухколоночный layout на десктопе
- Удаление с подтверждением

### На усмотрение Claude Code
- Мобильная адаптация (список + раскрытие summary по клику, или отдельный экран)
- Анимации при выборе чата и удалении
- Виртуализация списка (если чатов очень много)
- Точный дизайн правой колонки

### Не входит в это ТЗ
- Поиск по чатам (позже, когда чатов станет много)
- Фильтрация/сортировка (не нужна пока)
- Массовое удаление (позже)
- Фоновая генерация summary для старых чатов (низкий приоритет)

## Критерий готовности

- На Главной карточка "💬 История чатов" ведёт на `/chats`
- На `/chats` вижу список общих чатов слева, summary справа
- Кликаю на чат — справа появляется summary и кнопки
- Нажимаю "Открыть чат" — попадаю в чат
- Нажимаю "Удалить" — подтверждение → чат удалён
- Новые чаты после 2-3 обменов получают и title, и summary автоматически
- Могу пометить чат ⭐ как важный (из списка и из sidebar)
- Breadcrumbs: `← Главная / История чатов`
