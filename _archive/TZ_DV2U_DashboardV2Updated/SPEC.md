# ТЗ: UX навигации Dashboard V2

**Версия:** 1.0 | **Дата:** 2026-02-18
**Контекст:** Dashboard V2 (v3.24.0) внедрён. Карточки, ListDetailPage, chatMode работают. Нужно привести терминологию и навигацию в порядок.

---

## Зачем

Пользователь теряет контекст при переходе из страницы инструмента в чат. Нет breadcrumbs, терминология не соответствует режимам (везде "чат" вместо "запрос"/"задание"), sidebar смешивает все типы чатов.

---

| chat | (поле ввода) | История чатов | чат | + Новый чат | 3 чата | — |
| expertise | Экспертиза | Экспертиза | запрос | + Новый запрос | 2 запроса | 🔍 |

### Что заменить

**Страница `/expertise`:**
- Счётчик: "N чатов" → "N запросов"
- Кнопка: "Новая экспертиза" → "Новый запрос"
- Детали: "О чём чат" → "О чём запрос"
- Кнопка деталей: "Открыть чат →" → "Открыть запрос →"
- Элементы списка: "N сообщ." — оставить как есть (сообщения универсальны)

**Страница `/create`:**
- Счётчик: "N чатов" → "N заданий"
- Кнопка: "Новое создание" → "Новое задание"
- Детали: "О чём чат" → "О чём задание"
- Кнопка деталей: "Открыть чат →" → "Открыть задание →"

**Страница `/chats`:**
- Добавить кнопку **"+ Новый чат"** в header справа (сейчас отсутствует, хотя на /expertise и /create есть). Создаёт чат с `chatMode: 'chat'`, редирект в `/chat`

**Единообразие всех трёх страниц:** каждая обязательно имеет кнопку создания в header:

| Страница | Кнопка создания |

## Часть 2: Breadcrumbs в чате

Когда пользователь открывает чат из страницы инструмента — в header чата должны быть breadcrumbs:

- Из `/expertise`: **Экспертиза** > Название запроса
- Из `/create`: **Создание** > Название задания
- Из `/chats`: **Чаты** > Название чата
- Обычный чат (с главной): без breadcrumbs (как сейчас)

Клик на первую часть breadcrumbs → возврат на страницу инструмента (`/expertise`, `/create`, `/chats`).

Breadcrumbs определяются по `chatMode` из БД:
- `chatMode: 'expertise'` → "Экспертиза > ..."
- `chatMode: 'create'` → "Создание > ..."
- `chatMode: 'chat'` → без breadcrumbs (или "Чаты > ..." если открыт из /chats)

Размещение: в chat-header, слева, перед заголовком. Паттерн уже есть в проектах (Breadcrumbs на всех уровнях).

## Часть 3: Контекст sidebar в чате

Сейчас AppSidebar показывает все чаты вперемешку. Нужна контекстная фильтрация:

- Чат открыт с `chatMode: 'expertise'` → sidebar показывает только запросы экспертизы
- Чат открыт с `chatMode: 'create'` → sidebar показывает только задания
- Чат открыт с `chatMode: 'chat'` → sidebar показывает только обычные чаты
- Обычный чат без chatMode → все чаты (как сейчас, backward compatible)

Кнопка "Новый чат" в sidebar → учитывает текущий chatMode:
- В экспертизе: "Новый запрос" → создаёт чат с `chatMode: 'expertise'`
- В создании: "Новое задание" → создаёт чат с `chatMode: 'create'`
- В обычном чате: "Новый чат" → создаёт чат с `chatMode: 'chat'`

## Не трогать

- Проектные чаты — своя навигация, своя структура
- Бен — без изменений
- Промпты — без изменений
- ListDetailPage layout — без изменений (только тексты)
- Дашборд — без изменений

---

## Ожидаемый результат

1. Терминология соответствует режимам: запрос/задание/чат
2. Breadcrumbs в header чата — пользователь всегда знает где он
3. Sidebar фильтрует чаты по текущему режиму
4. Кнопка создания в sidebar учитывает текущий chatMode
5. Навигация "назад" из чата ведёт на правильную страницу инструмента
