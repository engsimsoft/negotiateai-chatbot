# Анализ ТЗ-KITT: Simply — Persistent Chat

## Резюме

Переход от модели "множественные чаты" к модели "один постоянный разговор" (KITT) для основного режима. Экспертиза, Создание, Проекты — без изменений. Simply-KITT = дворецкий: быстрые ответы (Haiku), кнопка «Думать» (Sonnet), маршрутизация серьёзных задач в Экспертизу/Создание/Проекты.

## Принятые архитектурные решения (brainstorm 2026-04-07)

### 1. Кнопка «Думать»
- По умолчанию KITT работает на **Haiku** (быстро, дёшево)
- Кнопка «Думать» → конкретное сообщение уходит на **Sonnet**
- Следующее сообщение — снова Haiku автоматически
- Одна кнопка, без выбора моделей. Apple-подход для аудитории 40-60+
- Opus остаётся территорией Экспертизы и Проектов

### 2. Роль KITT — дворецкий-маршрутизатор
- Быстрые вопросы → отвечает сам (Haiku)
- Запомнить идею/факт/задачу → мгновенно в MIND
- Серьёзный анализ → рекомендует Экспертизу
- Длинная генерация → рекомендует Создание
- Маршрутизация = рекомендация, не авторедирект
- PE-контракт: формулировки и поведение — задача Prompt Engineering

### 3. Защита от дрифта
- Роль дворецкого защищает — лёгкий контекст, compaction сжимает без потерь
- MIND как якорь — факты всегда в system prompt
- Dual strategy RAG-3 без изменений: Haiku → Snapshot, Sonnet → Compaction API

### 4. Старые чаты
- Не удаляются, доступны через «Архив» (пункт в sidebar → `/chats`)
- Удаление Simply-чата запрещено (скрыть кнопку delete)

## Рекомендации разработчика (Код-ревью)

### Согласен с концепцией
- Маршрут `/simply` — чистое решение, не ломает routes
- `chatMode: "simply"` — существующая система поддерживает без миграции
- Кнопка «Думать» — технически просто (toggle + параметр в route)
- Dashboard `/context` — самостоятельная страница с API
- Категория `idea` — одна строка в types + правка промпта
