**Версия:** 3.28.0  
**Зависимости:** нет  
**Приоритет:** 🔴 Блокирует ТЗ-А2 (онбординг брифинга) вместе с ТЗ-PX

---

## Цель

Новый tool `fetchUrl` — зайти по ссылке, прочитать содержимое страницы, вернуть текст. Модель сама анализирует полученный текст. Отдельный tool для анализа (`analyzeWebsite`) не нужен — это лишняя сущность, модель справляется сама.

---

## Реализация

### Файл: `lib/ai/tools/fetch-url.ts`

По паттерну `web-search.ts`:
- Vercel AI SDK `tool()` с `wrapToolExecution`
- inputSchema: `url` (string) + опционально `maxLength` (number, default 10000 символов — обрезка контента чтобы не забить контекст)
- Таймаут: 15 секунд
- Возвращает: текст страницы (очищенный от HTML), title, url, длину оригинала

### Извлечение текста

Используем `@mozilla/readability` — уже в стеке (фетчеры брифинга используют). Чистый текст без навигации, рекламы, футеров. Если readability не справляется (SPA, динамический контент) — fallback на базовый strip HTML.

### Tool description

```
Загрузить и прочитать содержимое веб-страницы по URL. Возвращает очищенный текст страницы.

Используй когда:
- Пользователь даёт ссылку и просит проанализировать
- Нужно проверить конкретный источник (живой? качественный? оригинальный контент или перепечатка?)
- deepResearch нашёл источник и нужно убедиться в его качестве

НЕ используй для: поиска информации (для этого webSearch или deepResearch).
```

### Регистрация

В `chat-tools.ts` → `getStandardTools()`:
- Добавить `fetchUrl`
- Добавить в `getActiveToolNames()`

### Доступность по режимам

| Режим | fetchUrl |
|-------|----------|
| Chat (Haiku) | ❌ |
| Экспертиза (Sonnet) | ✅ |
| Создать (Sonnet) | ✅ |
| Проекты (Sonnet/Opus) | ✅ |
| Service chats (онбординг) | ✅ |

Те же режимы что и `deepResearch` — они работают в паре.

### Tool Activity

В `tool-activity-config.ts`:
- Active label: "Читаю страницу..."
- Done label: "Страница прочитана"
- Result formatter: title страницы + количество символов
