## Цель

Три изменения на странице проекта:

1. **Папки для файлов** (1 уровень) — группировка файлов проекта по смысловым категориям
2. **Чаты → Задачи** — переименование терминологии внутри проектов
3. **Карточка "История задач"** рядом с инпутом + страница `/projects/[id]/tasks` по паттерну 07B

**Результат:** пользователь открывает проект → видит инпут с карточкой "История задач" (как на Главной) → файлы организованы в папки → внутри проекта всё называется "задачи", не "чаты".

## Часть 1. Папки для файлов (1 уровень)

### Что делаем

Файлы проекта можно группировать в папки. Один уровень — без вложенности. Папки видны в `ProjectFilesCard`.

### База данных

Новая таблица `ProjectFolder`:

| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | PK |
| projectId | uuid | FK → Project |
| name | varchar(100) | Название папки |
| emoji | varchar(10) | Эмодзи-иконка (по умолчанию 📁) |
| sortOrder | integer | Порядок отображения |
| createdAt | timestamp | Дата создания |

В таблице `ProjectFile` добавить:
- `folderId` (uuid, nullable, FK → ProjectFolder) — файл в папке или в корне

### UI в ProjectFilesCard

- Папки отображаются как раскрываемые группы (клик → показать/скрыть файлы внутри)
- Каждая папка: эмодзи + название + количество файлов + стрелка раскрытия
- Файлы без папки показываются под папками в секции "Без папки" (только если есть такие файлы)
- Кнопка "+ Новая папка" внизу списка → инлайн-ввод названия
- На папке меню ⋯ → "Переименовать", "Удалить" (удаление папки не удаляет файлы — они перемещаются в корень)

### Загрузка файла в папку

При загрузке файла (кнопка "Загрузить" или drag & drop):
- Если есть папки — после загрузки показать dropdown "Выберите папку" со списком папок + "Без папки"
- Если папок нет — файл загружается в корень как сейчас

### Перемещение файла

На файле меню ⋯ → "Переместить в..." → список папок + "Без папки".

### API

- `POST /api/projects/[id]/folders` — создать папку
- `PATCH /api/projects/[id]/folders/[folderId]` — переименовать, изменить emoji/sortOrder
- `DELETE /api/projects/[id]/folders/[folderId]` — удалить (файлы → корень)
- `PATCH /api/projects/[id]/files/[fileId]` — обновить folderId (перемещение)

## Часть 2. Чаты → Задачи (терминология)

### Что меняем

**Только внутри контекста проекта** переименовать "чаты" в "задачи":

- `ProjectChatsCard` → заголовок "ЗАДАЧИ" вместо "ЧАТЫ"
- "Новый чат" → "Новая задача"
- "Нет чатов" → "Нет задач. Поставьте первую задачу."
- Placeholder инпута: "Поставьте задачу по проекту..." (уже так)
- Sidebar проекта: если отображает чаты проекта — "задачи"
- В мета внизу: "Задач: N" вместо "Чатов: N"

### Что НЕ меняем

- Код, переменные, таблицы БД — остаются `chat`, `Chat`. Это терминология пользователя, не кода
- Общие чаты (Главная, /chats) — остаются "чатами"
- Роуты — `/projects/[id]/chat/[chatId]` остаются как есть

## Часть 3. Карточка "История задач" + страница

### Карточка рядом с инпутом

Тот же паттерн что на Главной (карточка "История чатов" + инпут):

```
[📋 История задач (5)]  [Поставьте задачу...          ⚡ Исполнитель ▾]
```

- Карточка слева от `ProjectInput`
- Показывает количество задач проекта
- Клик → переход на `/projects/[id]/tasks`
- Если задач 0 — карточку не показывать, инпут на всю ширину

### Страница `/projects/[id]/tasks`

**Точная копия паттерна `/chats` из 07B:**

- Двухколоночный layout: список задач слева, детали справа
- Каждая задача: название + дата
- Правая колонка: название, summary, дата, количество сообщений, кнопки "Открыть задачу →" и "Удалить"
- Кнопка "⭐ Важная" на каждой задаче (isStarred)
- Header: `← Кофейня на Арбате / История задач`
- Кнопка "+ Новая задача" в header
- Sidebar отсутствует
- Empty state: "Нет задач. Начните с Главной страницы проекта!"

### Summary для задач

Расширить механизм автонейминга (из 07B) на проектные чаты:
- После 2-го ответа AI генерировать title + summary
- Тот же endpoint `generate-title-summary`, та же логика
- Убедиться что он работает для чатов с `projectId IS NOT NULL`

### Что убираем со страницы проекта

`ProjectChatsCard` (правая колонка) — убирается полностью. Задачи теперь доступны через карточку "История задач" → страница `/projects/[id]/tasks`.

**Правая колонка временно пустая** — в следующем ТЗ (07C-2) там появится "Пульс проекта".

## Ограничения

### Обязательно
- Один уровень папок (без вложенности)
- Терминология "задачи" только в контексте проекта
- Паттерн карточка + страница истории — как в 07B
- Summary для проектных чатов

### На усмотрение Claude Code
- Анимации раскрытия папок
- Drag & drop файлов между папками (можно отложить, достаточно меню "Переместить в...")
- Drag & drop для сортировки папок
- Мобильная адаптация страницы `/tasks`
- Выбор эмодзи для папки (можно дефолтный 📁)

### Не входит в это ТЗ
- Пульс проекта (правая колонка) — 07C-2
- Превью файлов (клик → canvas) — отдельное ТЗ
- AI-помощь при загрузке файлов (предложение папки) — после Менеджера проекта
- Менеджер проекта — отдельное ТЗ

---

## Критерий готовности

- На странице проекта файлы можно группировать в папки (создать, переименовать, удалить папку)
- Файл можно переместить в папку или в корень
- Внутри проекта всё называется "задачи"
- Рядом с инпутом карточка "📋 История задач" ведёт на `/projects/[id]/tasks`
- На `/tasks` — двухколоночный layout с summary (как /chats)
- Новые задачи получают title + summary автоматически
- Можно пометить задачу ⭐
