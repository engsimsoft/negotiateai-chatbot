# Анализ ТЗ-BRIEFING-AUTHOR-CLAUDE

**Дата:** 2026-02-21

---

## Резюме

Замена провайдера генерации брифинга с Gemini 3 Pro на Claude Sonnet 4.6. Причина — Gemini не соблюдает volume-инструкции при `generateObject` (15.6% от лимита output-токенов). Дополнительно — настройка `effort` (adaptive thinking) для всех точек на моделях Sonnet 4.6 и Opus 4.6.

## Потенциальные риски

1. **thinking + generateObject** — адаптивное мышление может быть несовместимо с `generateObject` (structured output). **Митигация:** ТЗ разрешает убрать thinking если не работает; Claude без thinking уже лучше Gemini.
2. **SDK версия** — `@ai-sdk/anthropic@2.0.63` (v2, не v3). **Проверено:** типы подтверждают поддержку `thinking: { type: 'adaptive' }` и `effort` в `node_modules/@ai-sdk/anthropic/dist/index.d.ts:138-161`.
