# ТЗ-07C-3: Точки входа на странице проекта

**Версия:** 1.1  
**Дата:** 2026-02-05  
**Для:** Claude Code (VS Code)  
**Базовая версия проекта:** после завершения ТЗ-07C-2  
**Зависит от:** ТЗ-07C-1 (папки, задачи), ТЗ-07C-2 (Пульс проекта)

---

## Цель

Заменить поле ввода на странице проекта тремя карточками действий. Проект — это рабочее пространство, не чат. Пользователь не "пишет в поле", а совершает осознанные действия: смотрит историю, ставит задачу, обращается к менеджеру.

**Было:** `[📋 История задач] + [текстовый инпут]`  
**Стало:** `[📋 История задач] + [➕ Новая задача] + [👤 Менеджер]`

---

## Часть 1. Убрать инпут

Удалить текстовое поле ввода со страницы проекта. Оно больше не является точкой входа в задачу.

---

## Часть 2. Карточка "Новая задача"

- Визуально аналогична карточке "История задач" (тот же размер, стиль)
- Иконка ➕ или аналогичная
- Текст: "Новая задача"
- **Клик** → создаёт новый чат в проекте и переходит в него (та же логика что была у инпута, только без предзаполненного текста)

---

## Часть 3. Карточка "Менеджер" (заглушка с превью)

Карточка открывает модальное окно с **экраном быстрых действий** — пользователь сразу видит что Менеджер умеет, даже если функция ещё не работает.

### Модальное окно Менеджера

```
┌──────────────────────────────────────────┐
│  👤 Менеджер проекта                  ✕  │
│                                          │
│  Чем помочь?                             │
│                                          │
│  ┌──────────────┐  ┌──────────────┐      │
│  │ 📁 Разобрать │  │ 📊 Подвести  │      │
│  │    файлы     │  │    итог      │      │
│  └──────────────┘  └──────────────┘      │
│  ┌──────────────┐  ┌──────────────┐      │
│  │ 📝 Изменить  │  │ 📋 Разбить   │      │
│  │  инструкцию  │  │  на задачи   │      │
│  └──────────────┘  └──────────────┘      │
│                                          │
│  ┌──────────────────────────────────┐    │
│  │ Или опишите что нужно...         │    │
│  └──────────────────────────────────┘    │
│                                          │
│  Менеджер проекта появится в ближайшем   │
│  обновлении.                             │
└──────────────────────────────────────────┘
```

### Четыре действия (карточки внутри модалки)

| Карточка | Иконка | Описание |
|---|---|---|
| Разобрать файлы | 📁 | Организовать файлы по папкам |
| Подвести итог | 📊 | Сводка состояния проекта |
| Изменить инструкцию | 📝 | Обновить цели и контекст проекта |
| Разбить на задачи | 📋 | Декомпозиция цели на конкретные задачи |

### Поведение (заглушка)

- Карточки действий визуально кликабельны, но **неактивны** (серые или с замочком)
- Поле ввода внизу — заблокировано
- Внизу модалки текст: "Менеджер проекта появится в ближайшем обновлении"
- Кнопка "Понятно" или просто крестик ✕ закрывает модалку

**Смысл заглушки:** пользователь при первом визите нажимает "Менеджер", видит четыре действия и понимает: "ага, здесь мне помогут навести порядок — с файлами, итогами, инструкцией". Это онбординг без объяснений.

---

## Ограничения

### Обязательно
- Три карточки в ряд, визуально единый стиль
- Карточка "Новая задача" работает (создаёт чат и переходит)
- Карточка "Менеджер" — модалка с экраном быстрых действий (заглушка)
- Инпут убран со страницы проекта

### На усмотрение Claude Code
- Иконки карточек (эмодзи или Lucide icons)
- Адаптация карточек на мобильных (стэк или скролл)
- Визуальный стиль неактивных карточек в модалке (серые, замочек, или opacity)
- Анимации

### Не входит в это ТЗ
- Логика Менеджера проекта (промпт, модель, розовые чаты, tool calling)
- Изменение поведения Эксперта при встрече пользователя
- Любые изменения в Пульсе проекта или папках

---

## Критерий готовности

- На странице проекта вместо инпута — три карточки в ряд
- "История задач" работает как раньше (переход на /tasks)
- "Новая задача" создаёт чат в проекте и переходит в него
- "Менеджер" открывает модалку с четырьмя действиями (все неактивны)
- Модалка показывает текст о будущем обновлении
- Визуально карточки выглядят как единая группа
