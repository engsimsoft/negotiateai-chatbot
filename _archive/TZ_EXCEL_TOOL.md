## 1. Цель

Создать инструмент для работы с Excel-файлами, который позволяет пользователям создавать, просматривать, редактировать и скачивать профессиональные таблицы через диалог с AI-агентами.

**Философия:** iPhone-уровень качества. Пользователь говорит "сделай бюджет" — получает профессионально оформленный файл с формулами, графиками и правильным форматированием.

---

## 2. Целевая аудитория

- Бизнес-пользователи 40+ без технического бэкграунда
- Люди, которые постоянно работают в Excel
- Не хотят разбираться в формулах — хотят результат

**Типичные запросы:**
- "Сделай таблицу расходов за месяц"
- "Добавь колонку с процентами"
- "Построй график по категориям"
- "Посчитай итоги"

## 3. Функциональные требования

### 3.1 Создание файлов

| Возможность | Описание |
|-------------|----------|
| С нуля | Любая структура по описанию пользователя |
| По шаблону | 10 готовых профессиональных шаблонов |
| Несколько листов | Табы с разными данными |
| Формулы | Все базовые и средние формулы |
| Графики | Столбчатые, линейные, круговые, области |
| Форматирование | Профессиональные стили, цвета, шрифты |

### 3.2 Анализ загруженных файлов

| Возможность | Описание |
|-------------|----------|
| Парсинг структуры | Понимание колонок, типов данных, формул |
| Ответы на вопросы | "Где перерасход?", "Какой итог за март?" |
| Выводы и рекомендации | "Транспорт стабильно выше плана на 15%" |

### 3.3 Редактирование

| Возможность | Описание |
|-------------|----------|
| Добавление | Колонки, строки, листы, графики |
| Изменение | Данные, формулы, форматирование |
| Удаление | Любые элементы |
| Пересчёт | Автоматический при изменениях |

### 3.4 Диалоговые итерации

Ключевая фича. Пользователь работает с файлом через диалог:

```
Пользователь: Сделай бюджет на январь
AI: [создаёт таблицу, показывает в артефакте]

Пользователь: Добавь категорию "Подписки"  
AI: [обновляет артефакт, пересчитывает итоги]

Пользователь: Сделай график расходов
AI: [добавляет диаграмму в артефакт]

Пользователь: Отлично, скачаю
AI: [кнопки скачивания .xlsx и .pdf]
```

Каждое изменение — мгновенное обновление артефакта.

### 3.5 Экспорт

| Формат | Описание |
|--------|----------|
| .xlsx | Основной формат, все формулы работают |
| .pdf | Для отправки клиентам, партнёрам |

## 4. Артефакт Excel

### 4.1 Требования к артефакту

Артефакт открывается в правой панели (холст), как существующие презентации.

**Компоненты:**

| Элемент | Описание |
|---------|----------|
| Табы листов | Переключение между sheets |
| Таблица | Отображение данных с форматированием |
| Графики | Рендеринг диаграмм |
| Toolbar | Кнопки скачивания |

**Ограничения артефакта (это нормально):**

| Что НЕ работает в артефакте | Почему |
|-----------------------------|--------|
| Редактирование ячеек мышкой | Это не Google Sheets |
| Редактирование формул | Сложно, не нужно |
| Pivot Tables | Слишком сложно рендерить |

Редактирование происходит через диалог с AI, не через UI артефакта.

## 10. Техническая архитектура

### 10.1 Библиотека для генерации

**ExcelJS** — основная библиотека для создания .xlsx файлов.

Возможности:
- Создание workbooks и worksheets
- Все типы формул
- Стили, форматирование, условное форматирование
- Графики
- Защита листов
- Streaming для больших файлов

### 10.2 PDF экспорт

Варианты:
- Puppeteer: рендер HTML-таблицы в PDF
- pdf-lib + рендер таблицы
- LibreOffice headless (если на сервере)

Решение по конкретному подходу — на усмотрение при реализации.

### 10.3 LLM модель

**Gemini 2.5 Flash** — оптимальный выбор:
- Быстрая генерация структурированного JSON
- Достаточно умная для всех типичных задач
- Экономичная при массовом использовании

### 10.4 Файловая структура (рекомендация)

## 11. API инструментов для AI

### 11.1 createExcel

Создание нового файла.

```typescript
createExcel({
  filename: string,
  sheets: [{
    name: string,
    columns: [{
      header: string,
      key: string,
      width?: number,
      type?: 'text' | 'number' | 'currency' | 'percent' | 'date'
    }],
    data: Array<Record<string, any>>,
    formulas?: [{
      cell: string,      // "C2"
      formula: string    // "=B2/B10"
    }],
    charts?: [{
      type: 'column' | 'bar' | 'line' | 'pie' | 'area',
      title: string,
      dataRange: string, // "A1:B10"
      position: string   // "E2"
    }],
    styles?: {
      theme?: string,    // "corporate-blue"
      freezeHeader?: boolean,
      alternateRows?: boolean
    }
  }]
})
```

### 11.2 parseExcel

Чтение и анализ загруженного файла.

```typescript
parseExcel({
  fileUrl: string  // URL из Vercel Blob
})

// Возвращает:
{
  filename: string,
  sheets: [{
    name: string,
    rowCount: number,
    columnCount: number,
    columns: string[],
    preview: Array<Record<string, any>>, // первые 10 строк
    formulas: string[],
    summary: string  // AI-описание содержимого
  }]
}
```

### 11.3 editExcel

Редактирование существующего файла.

```typescript
editExcel({
  fileUrl: string,
  operations: [{
    type: 'addColumn' | 'addRow' | 'updateCell' | 'addFormula' | 'addChart' | 'deleteColumn' | 'deleteRow',
    sheet?: string,
    ...params
  }]
})
```

### 11.4 exportPdf

Экспорт в PDF.

```typescript
exportPdf({
  fileUrl: string,
  options?: {
    orientation?: 'portrait' | 'landscape',
    paperSize?: 'A4' | 'Letter'
  }
})
```
