### Секции настроек

#### 1. Профиль (основная)

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| Полное имя | текст | да | Отображается в интерфейсе |

- Консалтинг
- E-commerce
- Производство
- Другое

## 🔧 Использование профиля агентами

### При каждом запросе к AI

```typescript
function buildSystemPrompt(agent: Agent, user: User): string {
  const userContext = `
# Информация о пользователе

- Имя: ${user.displayName || user.name}
- Обращение: на "${user.pronouns || 'вы'}"
${user.occupation ? `- Сфера: ${user.occupation}` : ''}
${user.bio ? `- Контекст: ${user.bio}` : ''}

`;

  return userContext + agent.systemPrompt;
}
```

### Приветствие на главной

```
Привет, ${user.displayName || user.name}! 👋
```

Вместо захардкоженного "Привет, julia!"

## 📎 Сценарии для тестирования

### Сценарий 1: Заполнение профиля

```
1. Открыть меню пользователя (левый нижний угол)
2. Нажать "Настройки"
3. Заполнить все поля профиля
4. Нажать "Сохранить"
5. Обновить страницу — данные сохранились
```

### Сценарий 2: Агент использует профиль

```
1. Указать в профиле: displayName = "Владимир", pronouns = "вы"
2. Сохранить
3. Открыть чат с любым агентом
4. Написать "Привет"
5. Агент должен обращаться на "вы" и использовать имя
```

### Сценарий 3: Приветствие на главной

```
1. Указать displayName = "Владимир"
2. Сохранить
3. Выйти и войти снова
4. На главной: "Привет, Владимир! 👋"
```
