## 1. Цель

Создать новую точку входа в приложение (Dashboard) и реструктуризировать навигацию по образцу Claude.ai.

**Бизнес-цель:** Пользователь видит понятную панель инструментов вместо сразу открытого чата. Подготовка к добавлению Проектов в ТЗ-03.

---

## 2. Что делаем

### 2.1. Dashboard (`/dashboard`)

Новая главная страница — панель инструментов.

**Содержимое:**
- Приветствие с именем пользователя ("Добрый день, {displayName}")
- Секция "Мои инструменты" с карточками
- Подсказка от Бена внизу

**Карточки инструментов:**

| Карточка | Иконка | Действие | Статус |
|----------|--------|----------|--------|
| Чат | 💬 | Переход на `/chat` | Активна |
| Проекты | 📁 | — | Заблокирована, метка "Скоро" |

**Примечание:** Карточки Переводчик, Диктофон, Исследование — будущие фазы, пока не добавлять.

**UI референс:** Первый скриншот в обсуждении (ASCII-макет).

### 2.2. Новый Sidebar

Sidebar по образцу Claude.ai с вкладками.

**Вкладки:**

| Вкладка | Иконка | Содержимое |
|---------|--------|------------|
| Search | 🔍 | Поиск по чатам (можно заглушка) |
| Chats | 💬 | Список чатов пользователя |
| Projects | 📁 | Заглушка "Скоро" (до ТЗ-03) |

**Секция Chats:**
- Кнопка "+ New chat" вверху
- Список чатов сгруппированный по времени (Сегодня, Вчера, Предыдущие 7 дней, и т.д.)
- Клик по чату → переход на `/chat/[id]`

**Где показывать Sidebar:**
- ✅ `/chat` — показывать
- ✅ `/chat/[id]` — показывать
- ❌ `/dashboard` — НЕ показывать
- ❌ `/settings` — НЕ показывать

### 2.3. Роутинг

| Путь | Назначение | Sidebar |
|------|------------|---------|
| `/` | Редирект на `/dashboard` | — |
| `/dashboard` | Панель инструментов | Нет |
| `/chat` | Новый чат (пустой) | Да |
| `/chat/[id]` | Конкретный чат | Да |
| `/settings` | Настройки | Нет |

### 2.4. Header

**На Dashboard:**
```
Simply                                    [❓] [👤]
```

**В Chat:**
```
Simply    [+ Новый чат]                [📝] [❓] [👤]
```

**Изменения:**
- Логотип "Simply" — клик ведёт на `/dashboard`
- Кнопка [+ Новый чат] — только в `/chat/*`
- Модальные помощники [📝] [❓] — везде

## 4. Требования

### 4.1. Функциональные

1. Dashboard загружается как главная страница
2. Карточка "Чат" ведёт на `/chat`
3. Карточка "Проекты" заблокирована (не кликабельна)
4. Sidebar показывает историю чатов
5. Переключение вкладок в Sidebar работает
6. Навигация между Dashboard ↔ Chat работает
7. Приветствие использует `displayName` из профиля пользователя

### 4.2. UX

1. Dashboard — чистый, без sidebar (это панель инструментов, не рабочее пространство)
2. Переход Dashboard → Chat должен быть очевидным (большая карточка)
3. Возврат Chat → Dashboard — через клик на логотип
4. Sidebar не должен прыгать/перезагружаться при переходе между чатами

### 4.3. Технические

1. Использовать существующие компоненты UI (shadcn)
2. Сохранить работоспособность существующего функционала чата
3. Сохранить модальных помощников (📝 ❓)
4. Сохранить работу с артефактами
