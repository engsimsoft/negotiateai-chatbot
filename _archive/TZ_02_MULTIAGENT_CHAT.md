## 🗄️ Изменения схемы БД

### Таблица `Message_v2` — добавить поле

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| agentId | uuid | нет | FK → agents.id. Какой агент отправил сообщение. null для сообщений пользователя |

### Таблица `Chat` — изменение семантики

| Поле | Было | Стало |
|------|------|-------|
| agentId | Единственный агент чата | Агент по умолчанию / последний активный агент |

**Логика:**
- `Chat.agentId` — агент, который отвечает если не указан @-mention
- При @-mention другого агента — `Chat.agentId` обновляется на нового агента
- Это позволяет "переключаться" между агентами естественно

### Миграция данных

Для существующих сообщений ассистента:
- Установить `Message.agentId` = `Chat.agentId` (текущий агент чата)

## 💬 @-mentions система

### Синтаксис

```
@Маркетолог проанализируй рынок доставки еды
@PromptAgent помоги сформулировать запрос
@Помощник как работает этот агент?
```

### Парсинг

- Триггер: символ `@` в начале слова
- Матчинг: по `name` агента (регистронезависимо)
- Также поддержать: `@helper`, `@marketer` (по slug)

### UI автокомплит

При вводе `@` показывать dropdown со списком агентов:

```
┌─────────────────────────┐
│ 🤝 Помощник             │
│ 📊 Маркетолог           │
│ ✍️ Копирайтер           │
│ 💡 Prompt-агент         │
│ ...                     │
└─────────────────────────┘
```

**Поведение:**
- Появляется при вводе `@`
- Фильтруется по мере ввода (`@Мар` → только Маркетолог)
- Enter или клик — вставляет упоминание
- Escape — закрывает

### Обработка сообщения

```
1. Пользователь отправляет: "@Маркетолог проанализируй рынок"
2. Парсинг: найден @Маркетолог
3. Загрузка агента из БД по имени/slug
4. Использование промпта Маркетолога
5. Ответ сохраняется с Message.agentId = id Маркетолога
6. Chat.agentId обновляется на id Маркетолога
```

### Без @-mention

Если сообщение без @-mention:
- Использовать `Chat.agentId` (текущий/последний агент)
- Это позволяет продолжать диалог с агентом без повторного упоминания

## 🤝 Агент-Помощник

### Роль

**Консьерж платформы.** Не решает задачи, а:
- Объясняет как работает платформа
- Рекомендует подходящих агентов
- Обучает эффективному общению с AI
- Помогает новичкам освоиться
- Координирует между агентами

### Добавить в каталог

| Поле | Значение |
|------|----------|
| slug | helper |
| type | system |
| name | Помощник |
| icon | 🤝 |
| description | Помогу разобраться в платформе, подскажу подходящего агента и научу эффективно формулировать запросы |
| defaultModel | gemini-3-pro |
| sortOrder | 1 (всегда первый) |

### Capabilities

```typescript
{
  superpowers: [
    "Навигация по агентам и их возможностям",
    "Обучение эффективному промптингу",
    "Подбор агента под задачу",
    "Объяснение работы инструментов",
    "Онбординг новых пользователей"
  ],
  exampleTasks: [
    "Какой агент поможет с анализом конкурентов?",
    "Как лучше сформулировать запрос для презентации?",
    "Что умеет Копирайтер?",
    "Я первый раз здесь, с чего начать?"
  ],
  limitations: [
    "Не выполняет задачи напрямую — направляет к специалистам",
    "Для создания контента используйте профильных агентов"
  ]
}
```

### Системный промпт

```markdown
# Роль

Ты — Помощник, консьерж платформы Simply. Твоя задача — помогать 
пользователям эффективно работать с AI-агентами.

# Что ты делаешь

1. **Навигация** — рекомендуешь подходящего агента под задачу
2. **Обучение** — объясняешь как формулировать запросы для лучших результатов
3. **Объяснение** — рассказываешь о возможностях агентов и инструментов
4. **Онбординг** — помогаешь новичкам освоиться

# Что ты НЕ делаешь

- Не пишешь тексты (это Копирайтер)
- Не анализируешь рынок (это Маркетолог)
- Не создаёшь презентации (это Презентатор)
- Не решаешь задачи напрямую — ты координатор

# Доступные агенты

{AGENTS_LIST}
<!-- Динамически подставляется список агентов с описаниями -->

# Стиль общения

- Дружелюбный и поддерживающий
- Конкретный — всегда предлагай следующий шаг
- Используй примеры для объяснения
- Если пользователь новичок — объясняй простыми словами

# Формат ответа

Когда рекомендуешь агента, используй формат:

"Для [задача] рекомендую **[Агент]**.

Он умеет: [краткие возможности]

Совет: [как лучше сформулировать запрос]

Напишите `@[Агент] [ваш запрос]` чтобы начать."
```

### База знаний Помощника (RAG) — подготовка

> **Примечание:** Полноценный RAG будет реализован позже. На этом этапе создаём структуру и наполняем базовым контентом через промпт.

**Будущая структура:**

```
knowledge/helper/
├── agents/           — описания всех агентов
├── tools/            — описания инструментов
├── prompting/        — гайды по промптингу
├── platform/         — FAQ, как работает
└── use-cases/        — примеры использования
```

**На этом этапе:** Вся информация включена в системный промпт + динамическая подстановка списка агентов.

## 💡 Prompt-агент

### Роль

**Переводчик с человеческого на AI.** Помогает пользователям формулировать эффективные запросы для других агентов.

### Добавить в каталог

| Поле | Значение |
|------|----------|
| slug | prompt-agent |
| type | catalog |
| name | Prompt-агент |
| icon | 💡 |
| description | Помогу сформулировать запрос так, чтобы AI понял вас правильно и дал лучший результат |
| defaultModel | gemini-3-pro |
| sortOrder | 2 (после Помощника) |

### Capabilities

```typescript
{
  superpowers: [
    "Улучшение размытых запросов",
    "Добавление контекста и деталей",
    "Структурирование сложных задач",
    "Перевод бизнес-задач в промпты",
    "Оптимизация запросов для генерации изображений"
  ],
  exampleTasks: [
    "Улучши запрос: 'напиши текст про продукт'",
    "Как попросить нарисовать логотип?",
    "Сформулируй задачу для анализа конкурентов",
    "Мой запрос не работает, помоги переформулировать"
  ],
  limitations: [
    "Не выполняет задачи сам — только помогает сформулировать",
    "Для выполнения задачи используйте профильного агента"
  ]
}
```

### Системный промпт

```markdown
# Роль

Ты — Prompt-агент, эксперт по формулировке запросов для AI. 
Твоя задача — помочь пользователю составить такой запрос, 
который даст максимально качественный результат.

# Что ты делаешь

1. Анализируешь исходный запрос пользователя
2. Выявляешь что не хватает (контекст, детали, формат)
3. Задаёшь уточняющие вопросы
4. Формулируешь улучшенный запрос
5. Предлагаешь отправить профильному агенту

# Техники улучшения запросов

## Добавление контекста
Плохо: "Напиши текст"
Хорошо: "Напиши текст для лендинга курса по Python. 
ЦА — начинающие разработчики 20-30 лет. Тон — дружелюбный, 
мотивирующий. Длина — 200 слов."

## Структурирование задачи
Плохо: "Проанализируй конкурентов"
Хорошо: "Проанализируй 5 конкурентов в нише [X]. 
Для каждого укажи: позиционирование, ЦА, цены, УТП, 
слабые места. Формат — таблица."

## Для генерации изображений
Плохо: "Нарисуй логотип"
Хорошо: "Минималистичный логотип для IT-стартапа. 
Название: TechFlow. Стиль: современный, геометрический. 
Цвета: синий и белый. Без текста, только символ."

# Формат ответа

После улучшения запроса предлагай:

"Вот улучшенный запрос:

[улучшенный запрос]

Напишите `@[Агент] [запрос]` или нажмите кнопку:

[Отправить [Агенту]]"

# Кнопки действий

Когда формулируешь финальный запрос, добавляй кнопку 
для отправки нужному агенту. Формат:

[button:Отправить Маркетологу|@Маркетолог {запрос}]
```

## 🔔 Подсказки системы

### Когда показывать

Система предлагает помощь в определённых ситуациях:

| Ситуация | Подсказка |
|----------|-----------|
| Первый чат пользователя | "Подсказка: напишите @Помощник если нужна помощь с платформой" |
| Короткий/размытый запрос | "💡 Нужна помощь с формулировкой? Попробуйте @PromptAgent" |
| Пользователь выражает непонимание | "🤝 @Помощник может объяснить возможности агентов" |
| Долго нет активности в чате | "💬 Напишите @Помощник если не знаете с чего начать" |

### Реализация

**Вариант А (простой):** Статичные подсказки в UI по условиям

**Вариант Б (умный):** Анализ сообщений на стороне клиента

Для MVP: **Вариант А** — достаточно показывать подсказку для новых пользователей и при первом сообщении в чате.

### UI подсказок

```
┌─────────────────────────────────────────────────────┐
│ 💡 Подсказка                                    ✕  │
│                                                     │
│ Напишите @Помощник чтобы узнать о возможностях     │
│ платформы, или @PromptAgent для помощи с запросом. │
└─────────────────────────────────────────────────────┘
```

- Появляется над полем ввода
- Можно закрыть (✕)
- Не показывать если пользователь уже использовал @-mentions

## 🔧 Технические требования

### API изменения

**POST /api/chat** (отправка сообщения)
- Парсить @-mentions из текста
- Определять целевого агента
- Возвращать `agentId` в ответе

**GET /api/agents/by-name/:name**
- Поиск агента по имени или slug (регистронезависимо)
- Для резолвинга @-mentions

### Динамическая подстановка в промпт Помощника

При загрузке промпта Помощника:
1. Загрузить список всех активных агентов
2. Сформировать текстовое описание каждого
3. Подставить в `{AGENTS_LIST}` в промпте

Формат:

```
## Маркетолог (@Маркетолог, @marketer)
Стратегия продвижения, анализ ЦА, позиционирование.
Инструменты: веб-поиск, анализ сайтов, документы.

## Копирайтер (@Копирайтер, @copywriter)
Тексты для соцсетей, рекламные материалы, посты.
Инструменты: веб-поиск, документы.

...
```

### Кнопки действий в сообщениях

Prompt-агент может генерировать кнопки в ответе:

```
[button:Отправить Маркетологу|@Маркетолог {текст запроса}]
```

**Парсинг и рендеринг:**
1. При рендеринге сообщения находить паттерн `[button:...]`
2. Рендерить как кликабельную кнопку
3. При клике — вставлять текст после `|` в поле ввода и отправлять
