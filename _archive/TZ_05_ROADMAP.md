**Сценарии из ТЗ:**

**Сценарий 1: Панель подсказок**
```
1. Новый пользователь открывает чат
2. Панель подсказок открыта автоматически
3. Видит 3 раздела: агенты, документы, файлы
4. Сворачивает раздел про файлы
5. Закрывает панель
6. Открывает новый чат — панель закрыта
7. Кликает на 💡 — панель открывается
8. Раздел про файлы всё ещё свёрнут (запомнилось)
```

**Сценарий 2: Создание markdown документа**
```
1. Пишет: "Напиши маркетинговый план"
2. Агент создаёт документ в холсте
3. Видит красиво отформатированный текст
4. Кликает 👁️ → режим редактирования (видит исходный markdown)
5. Кликает обратно → режим просмотра
```

**Сценарий 3: Скачивание**
```
1. Открывает markdown документ
2. Кликает ⬇️
3. Видит меню: PDF, Markdown
4. Выбирает PDF → скачивается файл
5. Открывает PDF → форматирование сохранено
```

**Сценарий 4: Публичная ссылка**
```
1. Кликает 🔗 на документе
2. Копирует ссылку
3. Отправляет коллеге
4. Коллега (без аккаунта) открывает ссылку
5. Видит красиво отформатированный документ
6. Скачивает PDF
```
