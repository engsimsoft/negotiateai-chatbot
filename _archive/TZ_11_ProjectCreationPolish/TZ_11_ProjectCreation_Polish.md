## Контекст

Страница создания проекта (`/projects/new`) реализована в ТЗ-10: split layout с чатом справа и live preview паспорта слева. Секретарь проводит интервью, поля заполняются автоматически через tool `updateProjectDraft`.

Что нужно: исправить баг скролла, сделать пустое состояние полезным, улучшить отображение инструкции.

---

## 1. Баг: скролл чата

### Проблема
Обе колонки зафиксированы — при длинном диалоге ответы секретаря уходят за экран и не видны. Пользователь не может прокрутить чат.

### Решение
- **Левая колонка (preview)** — `position: sticky; top: 0; height: 100vh; overflow-y: auto` — фиксирована, но скроллится внутри себя если контент длинный
- **Правая колонка (чат)** — `overflow-y: auto; height: 100vh` — независимый скролл, автопрокрутка к последнему сообщению
- Убедиться что `auto-scroll` к новым сообщениям работает (как в обычном чате)

### Ключевые файлы
- `app/(dashboard)/projects/new/project-creation-client.tsx` — split layout

---

## 2. Умный preview: подсказки вместо пустоты

### Проблема
При открытии страницы левая панель показывает пустые поля. Пользователь не понимает что тут будет и зачем.

### Решение
Пока поле не заполнено — показывать подсказку-placeholder внутри карточки поля. Подсказка исчезает плавно когда появляется реальный контент.

### Подсказки

**Название** (пока пустое):
```
Например: "Маркетинг кофейни", "Контент для блога", "Анализ конкурентов"
```

**Описание** (пока пустое):
```
Появится после вашего рассказа о задаче
```

**Инструкция для AI** (пока пустая):
```
Секретарь сформулирует на основе интервью — чем подробнее расскажете, тем точнее будет работать AI
```

### UX-детали
- Подсказки — приглушённый текст (`text-muted-foreground`), курсив или меньший размер
- При появлении реального контента — плавная замена (fade transition, ~200ms)
- Не использовать стандартный HTML placeholder — это кастомный UI-элемент внутри карточки

### Ключевые файлы
- `app/(dashboard)/projects/new/components/project-draft-preview.tsx`

## 3. Инструкция для AI: preview + полный просмотр

### Проблема
Инструкция для AI может быть длинной (несколько абзацев). Сейчас она отображается целиком в карточке, занимая слишком много места и ломая layout.

### Решение
Компактный preview с возможностью раскрыть полный текст.

### Поведение

**Карточка "Инструкция для AI":**
- Показывать **первые 4-5 строк** текста
- После них — **gradient fade-out** (текст плавно уходит в прозрачность)
- Кнопка/ссылка **"Читать полностью"** или иконка разворота (👁 или expand)
- По клику — открывается **FileViewer** в режиме read-only с полным текстом инструкции (Markdown рендеринг)

**Важно:**
- Никакой кнопки ручного редактирования — в Simply инструкции меняются только через диалог (с Менеджером проекта, после создания)
- FileViewer уже поддерживает Markdown — используем существующий компонент
- Если инструкция короткая (≤4 строк) — показывать целиком, без fade и кнопки

### Ключевые файлы
- `app/(dashboard)/projects/new/components/project-draft-preview.tsx` — карточка инструкции
- `components/file-viewer/file-viewer.tsx` — существующий FileViewer
- `components/markdown-viewer.tsx` — рендеринг Markdown

## 5. Промпт секретаря — техническая подготовка

### Контекст
Сейчас промпт секретаря шаблонный. Полноценная инструкция будет написана в проекте Prompt Engineering. Но техническая обвязка должна быть готова.

### Что обеспечить технически

**Tool `updateProjectDraft`** — убедиться что поддерживает:
- `name` — название проекта
- `description` — описание
- `instruction` — инструкция для AI (может быть длинной, несколько абзацев)

**Формат инструкции:**
- Хранить как plain text или Markdown
- Поле в БД — `text` (без ограничения длины)
- При отображении — рендерить как Markdown

**Что НЕ делаем в этом ТЗ:**
- Не пишем промпт секретаря (это Prompt Engineering)
- Не добавляем загрузку файлов (это будет в Менеджере проекта)
- Не добавляем шаблоны проектов

## Порядок реализации

```
1. Баг скролла (быстрый фикс)
   ↓
2. Умный preview с подсказками
   ↓
3. Инструкция: preview + fade + полный просмотр
   ↓
4. Проверка tool updateProjectDraft (поддержка длинных инструкций)
   ↓
5. Тестирование полного flow: открыл → поговорил → увидел заполнение → проверил инструкцию → создал
```

## Критерии готовности

- [ ] Чат скроллится независимо от левой панели
- [ ] Пустые поля показывают подсказки
- [ ] Подсказки плавно заменяются реальным контентом
- [ ] Длинная инструкция показывает preview (4-5 строк) + fade + "Читать полностью"
- [ ] Клик по "Читать полностью" открывает FileViewer с полным текстом
- [ ] Короткая инструкция (≤4 строк) показывается целиком без fade
- [ ] Кнопки ручного редактирования нет нигде
- [ ] Весь flow создания работает: интервью → live preview → просмотр инструкции → создание проекта
