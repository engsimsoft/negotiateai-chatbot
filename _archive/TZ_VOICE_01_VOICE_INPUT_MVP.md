## Цель

Добавить возможность голосового ввода сообщений в чат. Пользователь нажимает кнопку микрофона, говорит — текст появляется в поле ввода с возможностью редактирования перед отправкой.

---

## Действия для владельца проекта

### Получение API ключа AssemblyAI

1. **Регистрация:** Перейти на https://www.assemblyai.com/dashboard/signup
2. **Создать аккаунт** — бесплатно, без привязки карты
3. **Получить API ключ:** После входа перейти на https://www.assemblyai.com/app/api-keys
4. **Скопировать ключ** и добавить в `.env.local`:
   ```
   ASSEMBLYAI_API_KEY=your_api_key_here
   ```

### Бесплатный лимит

- **$50 в кредитах** при регистрации
- Streaming: $0.15/час = **~333 часа бесплатно**
- Для тестирования более чем достаточно

## Технология

### AssemblyAI Universal-Streaming

| Параметр | Значение |
|----------|----------|
| **Endpoint** | `wss://streaming.assemblyai.com/v3/ws` |
| **Модель** | `universal-streaming-multilingual` |
| **Latency** | ~300ms |
| **Цена** | $0.15/час |

### Почему Universal-Streaming

- **Immutable transcripts** — текст не меняется после получения (в отличие от partial/final у других)
- **Встроенный Turn Detection** — умное определение конца реплики (semantic + acoustic)
- **Multilingual** — поддержка русского, английского и других языков
- **~300ms latency** — практически мгновенно

### Ключевые параметры подключения

```javascript
const params = {
  sample_rate: 16000,
  speech_model: 'universal-streaming-multilingual',
  
  // Turn Detection настройки (defaults, можно не указывать)
  end_of_turn_confidence_threshold: 0.4,      // Порог уверенности
  min_end_of_turn_silence_when_confident: 400, // ms тишины при уверенности
  max_turn_silence: 1280                       // ms максимальная тишина (fallback)
};
```

### Формат ответа от AssemblyAI

```json
{
  "transcript": "привет как дела",
  "utterance": "Привет, как дела?",
  "end_of_turn": true,
  "turn_is_formatted": true
}
```

**Важные поля:**
- `transcript` — сырой текст
- `utterance` — форматированный текст (с пунктуацией)
- `end_of_turn: true` — **сигнал для автостопа**
- `turn_is_formatted: true` — текст готов для отображения

## Требования к реализации

### Функциональные

1. **Кнопка микрофона** в интерфейсе ввода сообщения
2. **Запрос разрешения** на микрофон при первом использовании
3. **Запись и стриминг** аудио в AssemblyAI через WebSocket
4. **Автоматическая остановка** по `end_of_turn: true` от AssemblyAI
5. **Ручная остановка** — кнопка Стоп как fallback
6. **Результат** — текст в поле ввода, можно редактировать

### Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Нет разрешения на микрофон | Показать сообщение с инструкцией |
| Микрофон не найден | Показать сообщение об ошибке |
| Ошибка сети/WebSocket | Показать ошибку, предложить повторить |
| Нет API ключа | Не показывать кнопку микрофона |

### Технические

- **Аудио формат:** PCM 16-bit, 16000 Hz (требование AssemblyAI)
- **Размер чанка:** 50-1000ms аудио на chunk
- **Авторизация:** API ключ через серверный endpoint (не в браузере!)

## Архитектура

### Почему нужен серверный endpoint

API ключ AssemblyAI **нельзя** использовать напрямую в браузере — это security risk. Нужен backend endpoint для:

1. **Получения temporary token** от AssemblyAI
2. Или **проксирования WebSocket** соединения

### Рекомендуемый подход: Temporary Token

AssemblyAI поддерживает temporary tokens для браузерных приложений:

```
Browser → /api/assemblyai/token → AssemblyAI API → token
Browser → wss://streaming.assemblyai.com/v3/ws?token=xxx
```

### Упрощённая схема

```
┌─────────────────────────────────────────────────────────────┐
│                        БРАУЗЕР                              │
│                                                             │
│  1. Нажал 🎤                                                │
│  2. Запросил token с сервера                                │
│  3. Подключился к AssemblyAI WebSocket                      │
│  4. Захват аудио (Web Audio API + MediaRecorder)            │
│  5. Отправка chunks в WebSocket                             │
│  6. Получение transcript                                    │
│  7. end_of_turn: true → остановка                           │
│  8. Текст в поле ввода                                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    СЕРВЕР (Next.js)                         │
│                                                             │
│  /api/assemblyai/token                                      │
│  - Проверяет авторизацию пользователя                       │
│  - Запрашивает temporary token у AssemblyAI                 │
│  - Возвращает token браузеру                                │
└─────────────────────────────────────────────────────────────┘
```
