# ТЗ-BF3: BriefingSidebarRedesign

> Редизайн боковой панели брифинга: фирменный стиль, папки по темам, приоритизация кнопок

---

**Версия ТЗ:** 1.0
**Дата:** 2026-02-21
**Автор:** Claude Code (на основе обсуждения с пользователем)
**Версия проекта:** 3.40.0 → 3.41.0

---

## Контекст

Сайдбар брифинга визуально отличается от остального приложения. В чатовом интерфейсе (`app-sidebar.tsx`) есть фирменный header «S Simply», навигация домой, единый стиль. Сайдбар брифинга начинается сразу с контента, без брендинга, без пути домой через sidebar. Кнопки «Сгенерировать» и «Настройки» выглядят как обычные пункты навигации, не выделяясь визуально. «Настройки» дублируется в двух местах.

Кроме того, при масштабировании (5+ тем, активное сохранение) сайдбар станет неуправляемым: сохранённые темы группируются по дате брифинга, а не по смысловой категории.

---

## Цель

Привести сайдбар брифинга к единому фирменному стилю приложения Simply и решить проблему масштабируемости навигации по сохранённым темам.

---

## Требования

### 1. Фирменный header «S Simply»

**Что:** Добавить в верхнюю часть сайдбара брифинга брендированный header — терракотовый квадратик с «S» + надпись «Simply».

**Референс:** `app-sidebar.tsx:118-130` — точно такой же компонент.

**Поведение:**
- Клик → переход на `/dashboard`
- Визуально идентичен чатовому сайдбару

**Влияние на header страницы:**
- Стрелка `←` в `briefing-issue-header.tsx` скрывается на десктопе (`md:hidden`), т.к. навигация домой через «S Simply» в сайдбаре
- На мобильных стрелка остаётся (сайдбар скрыт)

### 2. Сохранённые темы: папки по категориям

**Что:** Изменить группировку сохранённых тем с «по дате брифинга» на «по теме (topicId/topicName)».

**Текущее состояние:**
```
СОХРАНЁННЫЕ
  21 фев, 18:13
    🤖 Разработки в области ИИ
  21 фев, 17:34
    🏎️ Формула-1
    🤖 Разработки в области ИИ
  21 фев, 17:04
    🏎️ Формула-1
  21 фев, 17:03
    🤖 Разработки в области ИИ
```

**Целевое состояние:**
```
🔖 СОХРАНЁННЫЕ
  ▸ 🏎️ Формула-1              2
  ▾ 🤖 Разработки в обл. ИИ   3
    21 фев · Amazon свалил вину...
    21 фев · OpenAI готовит колон...
    20 фев · Anthropic выпустил...
  ▸ 💰 Экономика               1
```

**Детали:**
- Группировка по `topicId` (у `SavedBriefingTopicClient` уже есть это поле)
- Каждая группа = Collapsible папка (компонент `Collapsible` из Radix UI)
- Папка показывает: `ChevronRight/Down` + `emoji` + `topicName` + `count`
- Внутри папки: элементы отсортированы по `savedAt DESC` (новые сверху)
- Каждый элемент внутри: `дата · title` (не topicName — он уже в заголовке папки)
- По умолчанию все папки свёрнуты (экономия места)
- Состояние раскрытия сохраняется в `localStorage`
- Hover на элементе: кнопка удаления `×` (как сейчас)
- Пустые папки (0 элементов) не показываются

### 3. Кнопка «Сгенерировать»: визуальный приоритет

**Что:** Сделать «Сгенерировать» полноценной primary-кнопкой вместо plain text.

**Текущее состояние:**
```
🔄 Сгенерировать    ← plain text, не выделяется
⚙️ Настройки        ← plain text, дублирует header
```

**Целевое состояние:**
```
[■■■ 🔄 Сгенерировать ■■■]    ← Button variant="default" (bg-primary)
```

**Детали:**
- `Button` компонент с `variant="default"`, `w-full`, `rounded-lg`
- Стиль: `bg-primary text-primary-foreground` (терракотовый, как «+ Новый чат»)
- AlertDialog при наличии существующего брифинга — сохраняется
- Иконка `RefreshCw` перед текстом

### 4. Удаление дубля «Настройки»

**Что:** Убрать кнопку «Настройки» из footer сайдбара. Оставить только шестерёнку в header страницы (`briefing-issue-header.tsx`).

**Обоснование:**
- Сейчас `⚙️ Настройки` есть в двух местах: footer сайдбара + header страницы
- Оба ведут на `/briefing/setup`
- В macOS-приложениях toolbar (header) отвечает за actions, sidebar — за навигацию

## Ограничения

- Использовать ТОЛЬКО семантические токены (docs/design-system.md)
- Hover паттерн B (inline): `hover:bg-muted/60` для навигационных элементов
- Active state: `bg-primary/10 font-medium text-primary`
- Collapsible: использовать существующий `components/ui/collapsible.tsx` (Radix UI)
- localStorage ключ: `briefing-sidebar-expanded-topics`
