# ТЗ: Tool saveFact — гарантированная запись в MIND

**Версия:** v3.75.0
**Приоритет:** Критичный
**Одна цель:** AI может гарантированно записать факт в MIND по явному запросу пользователя.

---

## Проблема

Пользователь говорит «запомни встречу в пятницу». AI отвечает «Запомнил!» — но ничего не записал. Extract работает в фоне и может подхватить факт, а может нет. AI врёт пользователю.

## Решение

Новый AI-tool `saveFact`, который KITT вызывает при явном запросе на запоминание. Tool записывает факт напрямую в `memory_entry` с embedding и категорией. Гарантированная запись — не «может подхватит», а «записано».

---

## Что сделать

### 1. Создать tool `saveFact`

Зарегистрировать новый tool в route Simply (chatMode=simply). Tool доступен ТОЛЬКО в Simply — не в Экспертизе, не в Создании, не в Проектах (там Extract справляется).

**Параметры tool:**

```typescript
{
  content: string,    // Текст факта. Обязательный.
  category: string,   // Одна из 7 категорий. Обязательный.
                      // Допустимые: "task" | "calendar" | "person" | "decision" | "idea" | "fact" | "preference"
}
```

**Что делает execute:**

1. Получает `content` и `category` от AI
2. Проверяет дедупликацию через существующий механизм RAG-2:
   - Генерирует embedding (Voyage AI voyage-4)
   - Ищет похожие факты (cosine > 0.55)
   - Если найден кандидат — Haiku верифицирует: дубликат или нет
   - Если дубликат — обновляет существующий факт (merge), не создаёт новый
3. Записывает в `memory_entry` с полями:
   - `content` — текст факта
   - `category` — категория
   - `source: "explicit"` — отличие от Extract (`source: "extracted"`)
   - `embedding` — вектор от Voyage AI
   - Остальные поля по существующей схеме (userId, createdAt, и т.д.)
4. Возвращает AI результат: `{ success: true, factId: "...", action: "created" | "merged" | "duplicate_skipped" }`

**Ответ AI пользователю** (формулировки — задача PE-контракта, здесь только техтребование):
- При `created`: показать «✓ Категория: текст факта»
- При `merged`: показать «✓ Обновлено: текст факта»
- При `duplicate_skipped`: сообщить что уже записано

### 2. Переиспользовать существующую инфраструктуру

НЕ создавать новые функции для embedding, дедупликации и записи. Использовать то, что уже работает в Extract pipeline:
- Embedding: та же функция что в RAG-1 (Voyage AI voyage-4)
- Дедупликация: тот же механизм что в RAG-2 (embedding candidates + Haiku)
- Запись в `memory_entry`: та же функция что в Extract

Claude Code: изучи текущий Extract pipeline, найди функции записи/embedding/дедупликации и переиспользуй их. Не дублируй код.

### 3. Поле `source` в memory_entry

Добавить различие между фактами из Extract и из saveFact:
- `source: "extracted"` — факт извлечён автоматически (Extract pipeline)
- `source: "explicit"` — факт записан явно (saveFact tool)

Если поля `source` нет в текущей схеме — добавить миграцию. Если есть аналог — использовать его. Claude Code: проверь схему `memory_entry` и реши.

### 4. Usage logging

Вызов saveFact должен логироваться через `saveAiUsageLog`:
- Embedding вызов (Voyage AI) — уже логируется если переиспользуется существующая функция
- Haiku вызов дедупликации — аналогично
- Отдельный лог для самого saveFact не нужен (это tool call, логируется в рамках основного AI-вызова)

### 5. Минимальное обновление промпта Simply

Добавить в существующий system prompt Simply **блок инструкций для saveFact**. Не переписывать весь промпт — только добавить секцию. Полная переработка промпта (роль KITT, маршрутизация, стиль) будет в отдельном PE-контракте позже.

**Добавить в промпт (суть, точные формулировки — на усмотрение Claude Code):**

```
## Память (MIND)

У тебя есть tool saveFact для записи фактов в память пользователя.

КОГДА ВЫЗЫВАТЬ:
Вызывай saveFact когда пользователь явно просит что-то запомнить или записать.
Триггеры и категории:
- «задача: ...» / «нужно сделать: ...» → category: "task"
- «встреча: ...» / «событие: ...» → category: "calendar"  
- «решение: ...» / «решили: ...» → category: "decision"
- «контакт: ...» / «человек: ...» → category: "person"
- «идея: ...» → category: "idea"
- «заметка: ...» / «запомни: ...» / «запиши: ...» → category: "fact"
- «я предпочитаю: ...» / «мне нравится: ...» → category: "preference"

ФОРМАТ ОТВЕТА:
После успешной записи: «✓ [Категория]: [текст факта]»
После обновления: «✓ Обновлено: [текст факта]»
Если дубликат: «Уже записано: [текст факта]»

ЗАПРЕТ:
Никогда не говори «Запомнил!», «Я это запомню» или «Записал!» БЕЗ вызова saveFact.
Если не уверен что запрос на запоминание — просто ответь, Extract подхватит в фоне.
```

---

## Чего НЕ делать

- НЕ переписывать промпт Simply целиком — только добавить блок про saveFact
- НЕ добавлять tool в Экспертизу/Создание/Проекты — только Simply
- НЕ создавать UI для saveFact — пользователь пишет в чат, AI вызывает tool
- НЕ менять Extract pipeline — он продолжает работать параллельно как раньше
- НЕ реализовывать подтверждение «Верно?» — записывать сразу

---

## Взаимодействие saveFact и Extract

Оба работают параллельно. Возможна ситуация: пользователь сказал «запомни встречу», saveFact записал, а Extract тоже извлёк тот же факт из сообщения. Дедупликация RAG-2 (embedding + Haiku) отловит это — тот же механизм работает и для Extract, и для saveFact. Дополнительной координации не нужно.

---

## Критерии приёмки (проверки в браузере)

1. **Записать факт:** написать в Simply «запомни: встреча с Григорием в пятницу в 14:00». Проверить: факт появился в `/settings/memory` с category=calendar
2. **Дедупликация:** написать тот же факт ещё раз. Проверить: нового факта не создано (merged или skipped)
3. **Все 7 категорий:** написать по одному факту каждой категории. Проверить: все 7 записаны с правильными категориями
4. **DevPanel:** проверить что embedding и дедупликация залогированы в usage
5. **Source:** в базе данных факт от saveFact имеет `source: "explicit"`, факт от Extract — `source: "extracted"`
6. **Экспертиза:** убедиться что tool saveFact НЕ доступен в Экспертизе (chatMode=expertise)
7. **Промпт работает:** написать «запомни: день рождения жены 15 марта». AI должен вызвать saveFact (видно в DevPanel), ответить «✓ Календарь: день рождения жены 15 марта»
8. **Запрет вранья:** написать что-то вроде «имей в виду, мне нравится зелёный чай» (без явного триггера). AI НЕ должен говорить «Запомнил!» — либо вызывает saveFact, либо просто отвечает нормально
