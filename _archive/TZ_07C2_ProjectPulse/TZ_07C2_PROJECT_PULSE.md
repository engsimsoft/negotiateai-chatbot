## Цель

Заполнить правую колонку на странице проекта — "Пульс проекта". Живая панель состояния: где мы сейчас, что сделано, что в работе. Пользователь вернулся через неделю — за 5 секунд в контексте.

**Результат:** на странице проекта справа панель "Пульс проекта" с итогом, статусами задач и быстрым доступом к последней задаче.

## Часть 1. Статус задачи

### База данных

В таблице `Chat` добавить:

| Поле | Тип | Описание |
|------|-----|----------|
| taskStatus | varchar(20) | 'not_started' / 'in_progress' / 'done'. Только для проектных чатов |

**Логика статусов:**
- `not_started` — задача создана, 0 сообщений пользователя
- `in_progress` — есть хотя бы 1 сообщение пользователя
- `done` — пользователь отметил как выполненную

Для общих чатов (projectId IS NULL) поле игнорируется.

### Как отметить "Готово"

На странице `/projects/[id]/tasks` (из 07C-1):
- В правой колонке (детали задачи) кнопка "✓ Отметить готово"
- После клика статус меняется на `done`
- Кнопка меняется на "↩ Вернуть в работу" (можно передумать)

В sidebar проекта:
- На задаче со статусом `done` показывать ✓
- Меню ⋯ → "Отметить готово" / "Вернуть в работу"

### API

- `PATCH /api/chat/[id]` — добавить поддержку `taskStatus`

## Часть 2. Пульс проекта (правая колонка)

### Компонент `ProjectPulse`

Располагается в правой колонке страницы проекта (где раньше был `ProjectChatsCard`).

### Структура панели

```
┌─────────────────────────────────┐
│ ═══════════════════════════════ │  ← цветная полоска сверху
│ 📊 Пульс проекта                │
│                                 │
│ ✅ 3 готово · 🔄 2 в работе · ○ 1│  ← статусы
│                                 │
│ ┌─────────────────────────────┐ │
│ │ ГДЕ МЫ СЕЙЧАС               │ │
│ │ Завершён анализ конкурентов │ │  ← итог проекта
│ │ и выбран логотип. В работе: │ │
│ │ контент-план и тексты сайта.│ │
│ └─────────────────────────────┘ │
│                                 │
│ АКТИВНЫЕ ЗАДАЧИ                 │
│ 🔄 Контент-план VK              │
│ 🔄 Текст для сайта              │
│                                 │
│ ПОСЛЕДНЯЯ ЗАДАЧА                │
│ ┌─────────────────────────────┐ │
│ │ Анализ конкурентов      → │ │
│ │ Обсудили 5 конкурентов...   │ │
│ │ Сегодня · ✅ Готово          │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

### Секции панели

**1. Статусы (всегда видно)**
```
✅ 3 готово · 🔄 2 в работе · ○ 1 не начато
```
Считается из taskStatus всех задач проекта.

**2. Итог проекта**
Блок "Где мы сейчас" — 2-4 предложения о текущем состоянии проекта.
- Хранится в `Project.summary` (новое поле, text, nullable)
- Генерируется AI на основе итогов (summary) всех задач проекта
- Показывать дату последнего обновления

**3. Активные задачи**
Список задач со статусом `in_progress` (максимум 5).
- Клик → переход в задачу
- Если нет активных — не показывать секцию

**4. Последняя задача**
Последняя задача по дате обновления.
- Название + summary (обрезанный до 2 строк) + статус
- Кнопка "Открыть →"

### Пустое состояние

Если задач нет:
```
📊 Пульс проекта

Пока нет задач. Поставьте первую задачу 
через поле ввода выше.
```

## Часть 3. Итог проекта

### База данных

В таблице `Project` добавить:

| Поле | Тип | Описание |
|------|-----|----------|
| summary | text | Сводный итог проекта |
| summaryUpdatedAt | timestamp | Когда обновлён итог |

### Когда обновлять

Итог проекта обновляется когда:
1. Задача отмечена как "Готово"
2. Пользователь явно попросил (кнопка "🔄 Обновить итог" в панели Пульса)

### Как генерировать

API endpoint `POST /api/projects/[id]/generate-summary`:
1. Получить summary всех задач проекта
2. Отправить в Gemini Flash с инструкцией:

```
Ты — менеджер проекта. На основе итогов задач напиши краткий статус проекта.

Задачи:
1. [название]: [summary] — [статус]
2. ...

Напиши 2-4 предложения:
- Что уже сделано
- Что сейчас в работе
- Что дальше (если понятно из контекста)

Пиши кратко, по делу, на русском.
```

### UI обновления

В панели Пульса:
- Под итогом мелким текстом: "Обновлён: сегодня, 14:30"
- Кнопка "🔄" рядом с заголовком "Где мы сейчас" — принудительное обновление

## Ограничения

### Обязательно
- Три статуса задач: not_started, in_progress, done
- Панель Пульса в правой колонке
- Итог проекта генерируется из итогов задач
- Кнопка "Отметить готово" на странице /tasks

### На усмотрение Claude Code
- Анимации при смене статуса
- Цветовая полоска сверху панели (можно градиент, можно solid)
- Сколько активных задач показывать (3-5)
- Формат даты обновления итога

### Не входит в это ТЗ
- AI сам предлагает "Отметить готово?" — это в инструкции Менеджера, отдельная задача
- Превью файлов — отдельное ТЗ
- Менеджер проекта (⚙️) — отдельное ТЗ

---

## Критерий готовности

- У проектных чатов есть статус (not_started / in_progress / done)
- На странице /tasks можно отметить задачу готовой
- На странице проекта справа панель "Пульс проекта"
- Пульс показывает: статусы, итог проекта, активные задачи, последнюю задачу
- Итог проекта генерируется из summary задач
- Можно обновить итог вручную (кнопка 🔄)
