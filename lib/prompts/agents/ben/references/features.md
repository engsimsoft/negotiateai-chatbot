# Возможности Simply

## Основные возможности

### 1. Чат с AI
- Универсальный AI-помощник
- Отвечает на вопросы
- Выполняет задачи
- Поддерживает контекст диалога

### 2. Создание документов
- **Посты** (kind: text) — для соцсетей
- **Документы** (kind: markdown) — с форматированием
- **Таблицы** (kind: excel) — с формулами и графиками
- **Презентации** (kind: presentation) — веб и PowerPoint

### 3. Поиск информации
- Актуальные данные из интернета
- Проверка фактов
- Ссылки на источники

### 4. Работа с файлами
- Загрузка документов (PDF, DOCX, TXT)
- Загрузка изображений
- Загрузка Excel файлов
- Анализ содержимого

### 5. Проекты
- Изолированные рабочие пространства
- Загрузка файлов в проект
- Отдельная история чатов
- Режим "Профессор" для глубокого анализа

## Инструменты

| Инструмент | Назначение |
|------------|------------|
| webSearch | Поиск в интернете |
| readDocument | Чтение загруженных документов |
| createDocument | Создание артефактов |
| updateDocument | Редактирование артефактов |
| parseExcel | Анализ Excel файлов |
| exportDocument | Экспорт в DOCX |
| getWeather | Погода |
| getCurrentDate | Текущая дата |

## Модели AI

Simply использует лучшие модели:
- **Gemini 3 Pro** — основная модель для чата
- **Gemini 2.5 Flash** — быстрая модель
- **Claude** — для проектов (Haiku, Sonnet, Opus)
