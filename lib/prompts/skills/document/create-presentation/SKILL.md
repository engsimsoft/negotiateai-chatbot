# Создание презентаций

## Когда использовать

- Пользователь просит "сделай презентацию", "нужны слайды"
- Требуется питч для инвесторов
- Нужен отчёт в формате слайдов
- Визуализация идеи или концепции

## Процесс работы

### 1. Уточни детали

Перед созданием спроси:
- **Цель:** Для чего презентация? (продать, обучить, отчитаться)
- **Аудитория:** Кто будет смотреть? (инвесторы, коллеги, клиенты)
- **Объём:** Сколько примерно слайдов? (5-7 коротко, 10-15 стандарт)
- **Формат:** Веб или PowerPoint?
- **Стиль:** Деловой, креативный, минималистичный?

### 2. Выбери формат

| Формат | Когда использовать |
|--------|-------------------|
| `presentation-reveal` | Показ онлайн, шеринг по ссылке |
| `presentation-pptx` | Скачать, редактировать, отправить по email |

### 3. Создай структуру

**Стандартная структура:**
1. Титульный слайд (название, автор)
2. Проблема / Контекст (зачем это нужно)
3. Решение / Основная часть (3-5 слайдов)
4. Результаты / Доказательства (если есть)
5. Выводы / Следующие шаги
6. Контакты / Call to action

### 4. Вызови tool

createDocument({
  type: 'presentation-reveal' или 'presentation-pptx',
  title: 'Название презентации',
  content: '... контент слайдов ...'
})

## Правила хороших слайдов

### Делай
- Один главный message на слайд
- Крупный читаемый текст
- Визуальная иерархия (заголовок → подзаголовок → текст)
- Пустое пространство — это хорошо

### Не делай
- Стены текста
- Мелкий шрифт "чтобы всё влезло"
- Больше 5-7 пунктов на слайде
- Читать слайды вслух дословно

## Примеры запросов

**Простой:**
> "Сделай презентацию про наш новый продукт"

**Детальный:**
> "Нужна презентация для инвесторов на 10 слайдов. Тема — приложение для доставки еды. Стиль деловой, формат PowerPoint."

## Частые ошибки

1. **Не спросил про аудиторию** → Презентация не попадает в цель
2. **Слишком много слайдов** → Аудитория устаёт
3. **Нет структуры** → Непонятно к чему ведёт
4. **Забыл call to action** → Что делать после просмотра?
