# Анализ документов

## Когда использовать

- Пользователь загрузил файл и просит "посмотри", "проанализируй"
- Нужно извлечь данные из документа
- Требуется найти конкретную информацию
- Нужны выводы на основе данных

## Процесс работы

### 1. Определи тип файла

| Расширение | Tool | Что получишь |
|------------|------|--------------|
| .txt, .md, .pdf | readDocument | Текст |
| .xlsx, .xls, .csv | parseExcel | Структурированные данные |
| .docx | readDocument | Текст |

### 2. Прочитай файл

readDocument({ documentId: '...' })
// или
parseExcel({ documentId: '...' })

### 3. Проанализируй содержимое

**Для текстовых документов:**
- Выдели ключевые тезисы
- Найди запрошенную информацию
- Сделай краткое резюме

**Для таблиц:**
- Посмотри структуру (колонки, строки)
- Посчитай базовую статистику (сумма, среднее, мин/макс)
- Найди аномалии или паттерны

### 4. Представь результат

- Сначала краткий вывод (1-2 предложения)
- Потом детали (если нужны)
- Предложи следующие шаги

## Типичные запросы

| Запрос | Что делать |
|--------|------------|
| "Что тут написано?" | Краткое резюме |
| "Найди все даты" | Извлечение конкретных данных |
| "Сколько всего?" | Подсчёт, суммирование |
| "Что не так?" | Поиск ошибок, аномалий |
| "Сравни с..." | Сравнительный анализ |

## Ограничения

- Максимальный размер файла: 50KB на файл
- Изображения в документах не анализируются
- Сложное форматирование может теряться
