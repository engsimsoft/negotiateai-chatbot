# Создание текстовых документов

## Когда использовать

- Пользователь просит "напиши документ", "создай отчёт"
- Нужна статья, пост, письмо
- Требуется инструкция, регламент, описание
- Любой структурированный текст

## Процесс работы

### 1. Уточни детали

Перед созданием спроси:
- **Тип:** Что это? (статья, письмо, отчёт, инструкция)
- **Аудитория:** Кто будет читать?
- **Тон:** Формальный, дружелюбный, нейтральный?
- **Объём:** Примерный размер?
- **Формат:** Нужно ли форматирование? (заголовки, списки)

### 2. Выбери формат

| Формат | Когда использовать |
|--------|-------------------|
| text | Простой текст без форматирования |
| markdown | С заголовками, списками, выделением |

### 3. Вызови tool

createDocument({
  type: 'markdown',
  title: 'Название документа',
  content: '... текст документа ...'
})

## Структуры по типам документов

### Статья / Пост
1. Заголовок (цепляющий)
2. Вступление (о чём и зачем)
3. Основная часть (разбить на секции)
4. Заключение (выводы, call to action)

### Деловое письмо
1. Приветствие
2. Суть вопроса (первый абзац)
3. Детали (если нужны)
4. Просьба / Предложение
5. Подпись

### Инструкция
1. Цель (что получим в результате)
2. Требования (что нужно для начала)
3. Шаги (пронумерованные)
4. Частые ошибки (опционально)
5. Контакты для вопросов

### Отчёт
1. Резюме (главное в 2-3 предложениях)
2. Контекст (что делали и зачем)
3. Результаты (с цифрами)
4. Проблемы (если были)
5. Следующие шаги

## Правила хороших документов

### Делай
- Начинай с главного
- Короткие абзацы (3-5 предложений)
- Подзаголовки для навигации
- Списки вместо перечислений в тексте

### Не делай
- Длинные вступления "ни о чём"
- Стены текста без разбивки
- Канцелярит и штампы
- Повторение одного и того же
