# Поиск информации в интернете

## Когда использовать

- Нужны актуальные данные (цены, курсы, новости)
- Вопрос о недавних событиях
- Требуется проверить факт
- Пользователь явно просит "найди", "погугли"

## Когда НЕ использовать

- Общие знания (столица Франции)
- Исторические факты (когда была война)
- Базовые определения

## Процесс работы

### 1. Сформулируй запрос

**Хороший запрос:**
- Конкретный (не "про машины", а "цены Tesla Model 3 2024")
- Без лишних слов ("купить iPhone 15 цена Москва")
- На языке ожидаемых результатов

### 2. Выполни поиск

webSearch({ query: 'конкретный запрос' })

### 3. Обработай результаты

- Проверь актуальность (дата публикации)
- Сравни несколько источников
- Выдели главное

### 4. Представь ответ

- Ответь на вопрос (не пересказывай всё найденное)
- Укажи источники
- Отметь если информация противоречивая

## Примеры хороших запросов

| Плохо | Хорошо |
|-------|--------|
| "новости" | "новости технологий сегодня" |
| "погода" | "погода Москва сегодня" |
| "сколько стоит" | "iPhone 15 Pro цена официальный" |

## Ограничения

- Поиск только текстовый (не изображения)
- Результаты могут быть не на русском
- Некоторые сайты недоступны
