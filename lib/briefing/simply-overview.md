# Simply — AI-платформа для бизнеса

Simply — рабочая AI-платформа, созданная для российских предпринимателей и руководителей. Платформа решает три проблемы, с которыми сталкивается бизнес при работе с зарубежными AI-сервисами: сложность оплаты, перегруженные интерфейсы и отсутствие адаптации под задачи бизнеса.

Принцип Simply — меньше элементов, каждый работает правильно. Один экран, понятные действия, результат без инструкций.

---

## Что работает сейчас

**Три режима общения с AI.** Обычный чат для быстрых вопросов работает на лёгкой модели. Режим экспертизы подключает более мощную модель для проверки фактов и точных ответов. Режим создания — та же мощная модель, настроенная на генерацию документов, презентаций и отчётов.

**Утренний брифинг.** Персональная новостная сводка по темам, которые важны именно вам. AI-автор анализирует источники и пишет аналитическую статью с карточками ключевых новостей. Темы и источники настраиваются через AI-собеседование — платформа сама задаёт правильные вопросы.

**Проекты.** Рабочее пространство для задач, требующих контекста и планирования. Три уровня AI внутри проекта: быстрый исполнитель для рутины, эксперт для основной работы, профессор для сложного анализа и стратегии. AI-менеджер ведёт проект, планирует задачи, проверяет результаты.

**Инструменты.** Поиск в интернете и глубокое исследование тем. Генерация документов и таблиц. Работа с загруженными файлами — PDF, Excel, изображения. Голосовой ввод. Web scraping с поддержкой русскоязычных источников.

---

## Что планируется

Аудио-подкаст в брифинге — два AI-ведущих обсуждают вашу новостную сводку в формате живого разговора.

Сохранение интересных тем из брифинга для отслеживания развития событий.

RAG-память по документам — платформа будет помнить содержимое ваших файлов и использовать его в работе.

Доставка брифинга в Telegram.
