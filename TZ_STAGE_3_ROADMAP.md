# Roadmap: Этап 3 — Агенты и персонализация

**Проект:** NegotiateAI Chatbot (Family AI Assistant)
**Версия:** 2.0.0 → 2.1.0
**Дата создания:** 2026-01-27
**Статус:** 🚧 В процессе

---

## 🎯 Цель этапа

Добавить систему агентов с уникальными промптами и инструментами. Каждый пользователь видит своих агентов в зависимости от роли (engineer/marketer).

**Пользователи:**
- **Юлия (marketer)** → 8 агентов: Маркетолог, Копирайтер, Переводчик, Кулинар, Астролог, Наставник, Универсальный, Одессит
- **Владимир (engineer)** → 3 агента: Наставник, Универсальный, Одессит

**Ключевые возможности:**
- Выбор агента при создании чата
- Уникальные system prompts для каждого агента
- Автоматический выбор AI модели по агенту (Gemini 3 Pro / Gemini 2.5 Flash)
- Иконки агентов в интерфейсе
- Приветственные сообщения
- Экспорт артефактов в DOCX (опционально)
