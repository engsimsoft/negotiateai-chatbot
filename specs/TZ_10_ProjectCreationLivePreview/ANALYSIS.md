## Критические баги (исправить первым делом)

### Баг 1: Диктовка теряет текст

**Приоритет:** CRITICAL

**Симптом:** При диктовке записываются только последние 1-2 слова, всё остальное теряется.

**Анализ:**
- `InputVoiceButton` использует `setValue(prev => prev + " " + text)`
- В controlled mode `setValue` использует `controlledValue` из closure
- При быстрых вызовах `onTranscript` closure содержит устаревшее значение

**Решение:** Использовать `useRef` для хранения актуального значения или изменить архитектуру.

### Баг 2: Нет attachments

**Приоритет:** HIGH

**Симптом:** Нет скрепки в ServiceChatInput.

**Решение:** Добавить `InputAttachments` + prop `showAttachments`.

### Баг 3: Нет VoiceMode

**Приоритет:** MEDIUM

**Симптом:** Нет кнопки голосового режима.

**Решение:** `showVoiceMode={true}` по умолчанию.

Сейчас есть 4 quick actions (Контент, Аналитика, Обучение, Бизнес).

**Вопрос:** Оставляем их? Если да, где размещать — в чате или под preview?

**Моё предложение:** Оставить в чате, показывать до первого сообщения (как сейчас).

### 2. Обязательные поля

**Вопрос:** Какие поля обязательны для создания проекта?

**Моё предложение:**
- `name` — обязательно
- `description` — обязательно

**Вопрос:** На mobile preview сворачивается или всегда виден?

## Потенциальные риски

### 1. Timing tool calls

**Риск:** AI может вызвать `updateProjectDraft` несколько раз подряд, вызывая "мерцание" preview.

**Митигация:** Debounce обновлений или accumulate changes перед применением.

### 2. Пустые/частичные обновления

**Риск:** AI вызывает tool с частичными данными, перезаписывая хорошие значения на пустые.

**Митигация:** Merge strategy — обновлять только непустые поля:
```typescript
setDraft(prev => ({
  ...prev,
  ...(result.name && { name: result.name }),
  ...(result.description && { description: result.description }),
}));
```

### 3. Рассинхрон при редактировании

**Риск:** Пользователь редактирует поле вручную, AI одновременно обновляет его.

**Митигация:** Если поле в фокусе (редактируется) — игнорировать AI updates для этого поля.
