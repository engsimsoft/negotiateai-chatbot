# Briefing Scriptwriter — User Message Template

> Этот шаблон формируется в коде (buildScriptwriterMessage). Здесь показана структура.

---

```
Дата выпуска: {briefingDate}

{IF isFirst}
## Контекст выпуска
Это первая секция. Начни с приветствия и краткого анонса.
Всего тем сегодня: {totalSections}.
Темы: {sectionTitles}
{/IF}

{IF isLast}
## Контекст выпуска
Это последняя секция. После обсуждения темы — завершение и прощание.
{/IF}

## Тема: {sectionTitle}

{sectionContent}
```

---

## Примечания для архитектора

**sectionContent** — поле `content` из `BriefingArticle.sections[i]`. Это markdown-текст, 300-800 слов. Может содержать inline-ссылки `[текст](url)` — сценарист их игнорирует.

**sectionTitles** — массив `topicName` из всех секций, через запятую. Пример: «технологии и AI, бизнес и финансы, геополитика». Нужен только для первой секции (анонс).

**Условные блоки** `{IF isFirst}` / `{IF isLast}` — реализовать в buildScriptwriterMessage через обычные if-ы. Для средних секций (не первая и не последняя) эти блоки не включаются.

**Поля sources из секции не передаются** — сценаристу они не нужны, он работает только с текстом.
