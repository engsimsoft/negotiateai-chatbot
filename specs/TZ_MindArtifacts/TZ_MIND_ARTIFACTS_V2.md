# ТЗ: Карточки MIND — визуализация (обновлённое)

**Версия:** v3.77.0
**Приоритет:** Высокий
**Зависимость:** saveFact v2 (metadata для task + calendar)
**Одна цель:** Нажатие на карточку MIND показывает данные в оптимальном формате: задачи — канбан, календарь — визуальный, остальное — чистые списки.

---

## Что изменилось

Предыдущая версия ТЗ: все 7 категорий — простые списки карточек.
Эта версия: задачи и календарь получают визуализации Notion-уровня благодаря metadata из saveFact v2. Остальные 5 категорий — списки (им метаданные не нужны).

---

## Что сделать

### 1. API endpoint (без изменений)

`GET /api/user/memory/context/[category]` — возвращает полные факты с metadata. Описан в ТЗ saveFact v2.

### 2. Навигация (без изменений)

Клик по карточке на `/context` → `/context/[category]`. Кнопка «Назад» → `/context`.

### 3. Визуализация по категориям

#### Задачи (task) → Канбан

Три колонки: **Новые** | **В работе** | **Сделано**

Группировка по `metadata.status`:
- `new` → колонка «Новые»
- `in_progress` → колонка «В работе»
- `done` → колонка «Сделано»
- `status` отсутствует → колонка «Новые» (по умолчанию)

Каждая карточка: текст задачи + дата создания. Компактно, без лишнего.

**Счётчик** над каждой колонкой: «Новые (3)», «В работе (1)», «Сделано (7)».

**Колонка «Сделано»:** карточки с приглушённым стилем (opacity или зачёркнутый текст) — выполненные задачи не должны визуально доминировать.

**Drag & drop — НЕ делать.** Изменение статуса — через чат («сделано: ...»). Apple-подход: одно действие, один способ.

**Mobile:** три колонки → горизонтальный скролл или вертикальные секции друг под другом.

#### Календарь (calendar) → Визуальный календарь

Месячная сетка с событиями на датах.

- События с `metadata.date` → показать на соответствующей дате в сетке
- События без `metadata.date` → секция «Без даты» под календарём (простой список)
- Текущий день — выделен
- Навигация: ← предыдущий месяц | сегодня | следующий месяц →
- Клик на день с событиями → раскрывает список событий этого дня (внизу или popup)
- Время события (если есть `metadata.time`) показывается рядом с названием: «14:00 Встреча с Григорием»

**Простой календарь**, не Google Calendar. Сетка дней, точки/бейджи на днях с событиями, раскрытие по клику.

**Mobile:** сетка сжимается, но остаётся читаемой. Дни без событий — компактнее.

#### Решения (decision) → Таймлайн

Вертикальная линия слева. Точки по датам. Каждый факт — карточка справа от линии. Новые сверху. Если фактов мало — выглядит как список, если много — красивая хронология.

#### Люди (person) → Карточки контактов

Карточки с аватаром-плейсхолдером (инициалы из первого слова content, цветной круг). Сетка 2-3 карточки в ряд. Каждая карточка: инициалы + полный текст факта.

#### Идеи (idea) → Список карточек

Простые карточки, новые сверху. Иконка 💡 (или CSS-аналог). Текст + дата.

#### Заметки (fact) → Список карточек

Простые карточки, новые сверху. Текст + дата.

#### Предпочтения (preference) → Компактный список

Плотный список без карточек. Каждый элемент — строка текста. Формат профиля/настроек.

### 4. Общие элементы для всех категорий

- **Заголовок:** иконка + название категории + count
- **Кнопка «Назад»** → `/context`
- **Empty state:** «Пока нет записей. Скажите Simply „задача: ..." чтобы добавить.» (текст адаптировать под категорию)
- **Дизайн:** дизайн-система «Тёплый интеллект», те же цвета что в карточках на `/context`
- **Без редактирования** — управление фактами через чат (saveFact, updateFact) и через `/settings/memory`

---

## Чего НЕ делать

- НЕ drag & drop в канбане — статус меняется через чат
- НЕ inline-редактирование — не Notion, пользователь говорит Simply
- НЕ фильтры и сортировки — мы выбрали оптимальный вид за пользователя
- НЕ переключение между views (таблица/канбан/список) — один формат на категорию
- НЕ пагинация — показать все факты, при 100+ использовать CSS max-height + scroll

---

## Дизайн

Следовать «Тёплый интеллект». Референс: Notion по структуре, Apple по простоте.

- Канбан: три колонки с лёгким фоном (coral-50 для новых, amber-50 для в работе, green-50 для сделанных)
- Календарь: чистая сетка, минимальные бордеры, точки-индикаторы на днях с событиями
- Mobile-friendly: канбан → вертикальные секции, календарь → компактная сетка

---

## Критерии приёмки

1. **Канбан задач:** создать 3 задачи (new, in_progress, done). На `/context/task` — три колонки с правильным распределением
2. **Календарь событий:** создать событие с датой. На `/context/calendar` — событие отображается на правильном дне в сетке
3. **Событие без даты:** создать событие без даты. Отображается в секции «Без даты» под календарём
4. **Навигация календаря:** переключение между месяцами работает
5. **Люди:** факты category=person отображаются как карточки с инициалами
6. **Решения:** факты category=decision отображаются как таймлайн
7. **Остальные:** idea, fact, preference — чистые списки
8. **Mobile:** канбан и календарь читаемы на мобильном
9. **Empty state:** категория без фактов показывает подсказку
10. **Скорость:** все страницы загружаются мгновенно (данные из БД, без AI-вызова)
