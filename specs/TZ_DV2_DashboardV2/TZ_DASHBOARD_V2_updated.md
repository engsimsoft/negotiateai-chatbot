## Что изменилось

Вместо простых карточек-ссылок — полноценные страницы для каждого инструмента. Паттерн страницы `/chats` (двухколоночный layout: список слева, детали справа) становится универсальным компонентом и переиспользуется для Экспертизы, Создать и Проектов.

## Этап 4: Карточки на дашборде + страницы инструментов

### 4.1 Три карточки на дашборде

Под блоком [История чатов + Поле ввода] — три карточки:

- **Экспертиза** — «Точные ответы с проверкой фактов»
- **Создать** — «Презентации, отчёты, изображения»
- **Проекты** — «Сложная работа с вашими данными»

Секцию ПРОЕКТЫ с карточками конкретных проектов — убрать с дашборда.

Карточку «История чатов» — не трогать.

Grid карточек должен быть расширяемым (будущие карточки: Утренний брифинг, Совещание и др.).

Дизайн — по `docs/design-system.md`.

### 4.2 Универсальный компонент ListDetailPage

Референс: существующая страница `/chats` (`components/chats/`). Тот же паттерн — список слева, детали справа. Но вместо копирования — переиспользуемый компонент.

**Конфигурация компонента:**

| Параметр | Экспертиза | Создать | Проекты |
|----------|------------|---------|---------|
| **Заголовок** | Экспертиза | Создать | Проекты |
| **Кнопка создания** | + Новая экспертиза | + Создать документ | + Новый проект |
| **Источник данных** | Чаты с `chatMode='expertise'` | Чаты с `chatMode='create'` | Таблица `Project` |
| **Правая панель** | summary чата, дата, кол-во сообщений, «Открыть чат →» | summary чата, дата, кол-во сообщений, «Открыть чат →» | Фаза, кол-во задач, прогресс, последняя активность, «Открыть проект →» |
| **Клик «Открыть»** | → `/chat/[id]` | → `/chat/[id]` | → `/projects/[id]` |
| **Кнопка создания →** | Создаёт чат с `chatMode:'expertise'`, редирект в `/chat/[id]` | Создаёт чат с `chatMode:'create'`, редирект в `/chat/[id]` | → `/projects/new` (существующий flow Секретаря) |

**Клик на карточку дашборда:**
- Экспертиза → `/expertise` (новая страница)
- Создать → `/create` (новая страница)
- Проекты → `/projects` (существующая страница, но переведённая на ListDetailPage)

### 4.3 Страницы

Три страницы с единым компонентом:

- `/expertise` — новая, route group `(dashboard)`, ListDetailPage с фильтром `chatMode='expertise'`
- `/create` — новая, route group `(dashboard)`, ListDetailPage с фильтром `chatMode='create'`
- `/projects` — существующая, рефакторить на ListDetailPage (правая панель показывает карточку проекта вместо summary чата)

### 4.4 Рефакторинг `/chats` → общий компонент

Текущие компоненты в `components/chats/` (chats-page-content, chat-list, chat-list-item, chat-detail-panel) — рефакторить в универсальный ListDetailPage. Страница `/chats` продолжает работать, но использует тот же компонент (фильтр: все чаты без chatMode или все).

### 4.5 Убрать селектор модели

- Убрать dropdown выбора модели из поля ввода (сейчас «Claude Sonnet ∨»)
- chatMode определяет модель автоматически, пользователь не выбирает
- **Обязательно оставить** индикатор модели под аватаркой AI в чате — dev-инструмент на время разработки

## Этап 5: AI = Simply + Badge chatMode

### 5.1 AI = Simply

- Аватар AI в сообщениях — логотип Simply (SparklesIcon пока, позже SVG)
- Имя AI — «Simply», не Claude/Sonnet/Haiku
- Подпись модели под аватаркой — dev-индикатор, сохраняется

### 5.2 Badge chatMode в истории

В sidebar и на страницах списков — маленький лейбл/иконка типа чата:
- 🔍 Экспертиза
- ✨ Создать
- 💬 Чат (или без бейджа — дефолт)

Чтобы пользователь отличал чаты в списке.
