# Патч: Усиление volume в buildUserMessage

**Файл:** `lib/briefing/briefing-author.ts`, функция `buildUserMessage()`
**Причина:** Одной строки `Объём выпуска: detailed` недостаточно. Gemini воспринимает это как метаданные, а не как требование. Нужен явный блок с цифрами.

---

## Что изменить

Заменить текущую строку volume в user message на развёрнутый блок. Конкретная реализация:

### Было (одна строка среди других настроек):
```typescript
const volumeLine = `- Объём выпуска: ${volume}`;
```

### Стало (блок с конкретными числами):
```typescript
function getVolumeInstruction(volume: string): string {
  switch (volume) {
    case "compact":
      return `## ТРЕБОВАНИЕ К ОБЪЁМУ: COMPACT
Общий объём: 600-1200 слов (3-5 минут чтения).
Каждая секция: 80-150 слов (обычная), 150-250 слов (приоритетная).
Стиль: кратко, только ключевые факты.`;

    case "detailed":
      return `## ТРЕБОВАНИЕ К ОБЪЁМУ: DETAILED
Общий объём: 3000-6000 слов (15-25 минут чтения).
Каждая секция: МИНИМУМ 400 слов (обычная), МИНИМУМ 700 слов (приоритетная).
Используй ВСЕ факты и цифры из полных текстов. Пиши развёрнуто: контекст, сравнения, аналитика, цитаты.
НЕ ОСТАНАВЛИВАЙСЯ пока не набрал минимум 3000 слов суммарно.`;

    default: // standard
      return `## ТРЕБОВАНИЕ К ОБЪЁМУ: STANDARD
Общий объём: 1500-3000 слов (8-12 минут чтения).
Каждая секция: 200-400 слов (обычная), 400-600 слов (приоритетная).`;
  }
}
```

### Где вставить в user message

В начало, перед списком кандидатов. Модель читает user message сверху вниз — требование к объёму должно быть первым что она видит:

```typescript
const userMessage = `${getVolumeInstruction(volume)}

Дата: ${dateFormatted}
Язык: ${language}
Целевое количество новостей: ${maxItems}

Темы пользователя:
${topicsFormatted}

---

Кандидаты (${candidates.length}):

${candidatesFormatted}`;
```

---

## Почему это важно

LLM воспринимают инструкции по-разному в зависимости от:
1. **Позиции** — начало и конец запоминаются лучше чем середина
2. **Формата** — заголовок с `##` воспринимается как структурный элемент, не как метаданные
3. **Конкретности** — "МИНИМУМ 400 слов" сильнее чем "400-700 слов"
4. **Повторения** — volume упоминается в system prompt (таблицы) + в user message (конкретные цифры) + в конце system prompt (critical reminders)

Три точки давления: system prompt начало → user message начало → system prompt конец. Это максимум что можно сделать промптом.
