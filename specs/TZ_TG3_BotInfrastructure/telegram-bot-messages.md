# @SimplyBot — Шаблоны сообщений и тон

**Контракт:** telegram-bot-messages
**Для:** ТЗ-TG4
**Версия:** 1.0

---

## Общие принципы тона

Бот — продолжение Simply, не отдельная личность. У него нет имени, нет характера, нет мнений. Он доставляет контент и помогает с настройками. Это курьер в хорошем костюме, а не собеседник.

**Тон:** спокойный, уважительный, лаконичный. На «вы». Без восклицательных знаков на каждом шагу. Без эмодзи-перегруза — максимум 1-2 на сообщение, функциональных (✅, ⚙️), не декоративных.

**Длина:** Telegram — не место для абзацев. Каждое сообщение — минимум слов для передачи сути. Если можно сказать в одном предложении — не пиши два.

**Чего не делать:**
- Не шутить, не каламбурить, не использовать мемы
- Не обращаться «друг», «дорогой», не фамильярничать
- Не писать «🎉🎊🥳» и подобное
- Не использовать капслок для акцентов
- Не извиняться многословно — коротко и по делу

## 1. Привязка аккаунта (/start)

### Успешная привязка

```
✅ Аккаунт Simply подключён.

Теперь брифинг будет приходить сюда каждое утро. Время и формат — в настройках Simply.
```

Inline-кнопка: `[Открыть Simply →]` (ссылка на /dashboard)

### Ошибка: ссылка истекла

```
Ссылка больше не действует — они работают 10 минут.

Откройте Simply и нажмите «Подключить Telegram» ещё раз.
```

Inline-кнопка: `[Открыть Simply →]` (ссылка на /settings или /dashboard)

### Ошибка: аккаунт уже привязан

```
Этот аккаунт Telegram уже связан с Simply.

Если хотите привязать другой аккаунт — сначала отключите текущий в настройках Simply.
```

Inline-кнопка: `[Настройки Simply →]` (ссылка на /settings)

### Холодный /start (без токена)

Человек нашёл бота сам — не перешёл по ссылке из Simply. У него может быть аккаунт Simply, а может не быть. Бот не знает.

```
Это бот Simply — доставляет утренний брифинг в Telegram.

Чтобы подключить, откройте Simply → Настройки → «Подключить Telegram».
```

Inline-кнопка: `[Открыть Simply →]` (ссылка на /settings)

Не пытаться объяснить что такое Simply, не продавать. Кто дошёл до бота — уже знает.

## 2. Доставка брифинга

### Структура сообщения

Одно сообщение = текстовая выжимка + кнопки. Аудио — отдельным сообщением следом (Telegram API: файл отправляется отдельно).

**Сообщение 1 — текст:**

```
Брифинг · {день недели}, {дата}

{выжимка: 5-7 ключевых пунктов}
```

Inline-кнопки (в одну строку):
`[Читать полностью]` `[⚙️ Настроить]`

**Сообщение 2 — аудио (если включено):**

MP3/OGG файл с подписью:

```
🎧 Аудио-версия · {длительность} мин
```

### Формат выжимки

Каждый пункт — одна строка, максимум два предложения. Эмодзи темы в начале (из профиля брифинга). Без нумерации — эмодзи достаточно для визуального разделения.

```
🏎️ McLaren показала ливрею 2026 — первая машина под новый регламент. Aston Martin и Alpine пока молчат.

💰 ЦБ оставил ставку 21%. Аналитики ждут снижения не раньше июня.

🤖 Anthropic выпустил Claude Opus 4.6 — модель обходит GPT-5 в бенчмарках рассуждений.

⚡ Газпром отчитался за 2025: выручка +18%, экспорт в Китай удвоился.

📱 Telegram обновил бот-платформу: мини-приложения теперь работают без загрузки.
```

Пункты — не копия статьи. Это самостоятельная выжимка для тех, кому достаточно заголовков. Кто хочет подробностей — нажмёт «Читать полностью».

### Подводка

Без подводки. День недели и дата — достаточный заголовок. Ежедневное «Доброе утро! Вот ваш брифинг!» — раздражает к третьему дню. Бот не здоровается — он доставляет.

### Генерация выжимки

Выжимка генерируется из готового BriefingArticle. Для каждой секции: emoji + одно-два предложения, суммирующих ключевой факт. Не AI-генерация в боте — берём из article.sections, сокращаем.

Если секций больше 7 — берём 7 самых важных (по порядку в статье, первые = важнее).
Если секций меньше 5 — показываем сколько есть, не раздуваем.

## 3. Сервисные сообщения

### Повторный /start (был отключён, вернулся)

Если пользователь ранее использовал /stop, а теперь снова /start:

```
С возвращением. Доставка брифинга включена.

Завтра утром придёт первый выпуск.
```

Без лишних вопросов, без «мы скучали», без выяснения причин ухода.

### Команда /help

```
Simply Bot — доставка утреннего брифинга.

/stop — приостановить доставку
/start — возобновить доставку

Настройки брифинга, темы и источники — в Simply.
```

Inline-кнопка: `[Открыть Simply →]`

Минимум. Бот делает одно дело — доставляет. Не нужно описывать все возможности Simply.

### Команда /stop

```
Доставка приостановлена.

Аккаунт Simply остаётся активным. Чтобы возобновить — отправьте /start.
```

Без «нам жаль», без «расскажите почему», без опросов. Уважаем решение.

### Ошибка доставки (пользователь заблокировал бота)

Бот не может отправить сообщение → уведомление в Simply:

В UI брифинга (или настройках): небольшой баннер или статус:

```
Доставка в Telegram не работает — бот заблокирован. Включите его заново в Telegram или отключите доставку.
```

Inline-кнопка в UI Simply: `[Отключить Telegram-доставку]`

Бот в этом случае ничего не отправляет (он заблокирован), уведомление только в Simply.

### Неизвестная команда или произвольный текст

Пользователь может написать боту что угодно. Бот не ведёт диалог.

```
Я доставляю брифинги, но не веду переписку.

Если нужно что-то обсудить или спросить — это в Simply.
```

Inline-кнопка: `[Открыть Simply →]`

Одинаковый ответ на любой текст, любую команду кроме /start, /stop, /help. Не пытаться распарсить намерение пользователя.

## 4. Inline-кнопки — спецификация

| Кнопка | Текст | Тип | URL |
|--------|-------|-----|-----|
| Читать полностью | `Читать полностью` | url | `{SIMPLY_URL}/briefing` |
| Настроить | `⚙️ Настроить` | url | `{SIMPLY_URL}/briefing/setup` |
| Открыть Simply | `Открыть Simply →` | url | `{SIMPLY_URL}/dashboard` |
| Настройки Simply | `Настройки Simply →` | url | `{SIMPLY_URL}/settings` |

Все кнопки — url-типа (открывают браузер). Не callback_query — бот не обрабатывает нажатия, только перенаправляет.

## 5. Технические заметки для архитектора

**Выжимка брифинга.** Рекомендую генерировать на стороне сервера при создании Telegram-сообщения, не через отдельный AI-вызов. Алгоритм: для каждой section из BriefingArticle взять emoji + первое предложение content (или source с наивысшим tier). Если нужна лучшая выжимка — можно добавить поле `telegramSummary` в BriefingArticleSection и генерировать его в briefing-author (одно предложение на секцию). Но это усложнение второго порядка.

**Длина сообщения.** Telegram ограничивает текстовое сообщение 4096 символами. Выжимка из 7 пунктов по 1-2 предложения + заголовок ≈ 600-900 символов. Запас большой.

**Аудио.** Telegram принимает MP3 и OGG (voice). MP3 отображается как файл с плеером. OGG voice — как голосовое сообщение (круглая иконка). Рекомендация: OGG для голосового ощущения, MP3 если хочется «подкастного» формата с обложкой. Решение за архитектурой.
