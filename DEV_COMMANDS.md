## 🚀 Запуск приложения

### Development режим (разработка)

```bash
npm run dev
```

**Особенности:**
- ⚡ Горячая перезагрузка (изменения видны сразу)
- 🐌 Первый запрос медленный (компиляция на лету)
- 🔍 Подробные ошибки и отладка
- 📝 Изменения в коде подхватываются автоматически

**Порт:** `http://localhost:3000` (или 3001, 3002 если 3000 занят)

---

### Production режим (финальная версия)

```bash
# Шаг 1: Сборка
npm run build

# Шаг 2: Запуск
npm run start
```

**Особенности:**
- 🚀 Очень быстрый (всё предкомпилировано)
- ⚡ Оптимизированный код
- ❌ НЕТ горячей перезагрузки
- ✅ Как на production (Vercel)

**Порт:** `http://localhost:3000` (по умолчанию)

## 🛑 Остановка процессов

### Остановить процесс на конкретном порту

```bash
# Порт 3000
lsof -ti:3000 | xargs kill -9

# Порт 3001
lsof -ti:3001 | xargs kill -9

# Порт 3002
lsof -ti:3002 | xargs kill -9
```

### Остановить все Node.js процессы

```bash
killall node
```

⚠️ **Внимание:** Остановит ВСЕ Node.js процессы на компьютере!

## 🔍 Проверка процессов

### Проверить что запущено на порту

```bash
# Проверить порт 3000
lsof -i:3000

# Проверить все Node.js процессы
ps aux | grep node

# Проверить все занятые порты
lsof -i -P | grep LISTEN
```

### Проверить что порт свободен

```bash
lsof -ti:3000 || echo "Порт 3000 свободен"
```

## 🧹 Очистка кеша

### Очистить кеш Next.js

```bash
# Удалить папку .next
rm -rf .next

# Перезапустить dev сервер
npm run dev
```

**Когда нужно:**
- Изменения не подхватываются
- Странные ошибки компиляции
- После изменения структуры роутинга

### Полная очистка

```bash
# Удалить все зависимости и кеш
rm -rf node_modules .next

# Переустановить зависимости
npm install

# Запустить
npm run dev
```

## 🐛 Отладка проблем

### Проблема: Порт 3000 занят

```bash
# Остановить процесс на порту 3000
lsof -ti:3000 | xargs kill -9

# Или запустить на другом порту
PORT=3001 npm run dev
```

### Проблема: Изменения не видны в браузере

1. **Обновить страницу:** `Cmd+R` (Mac) или `F5` (Windows)
2. **Жесткое обновление:** `Cmd+Shift+R` (Mac) или `Ctrl+Shift+R` (Windows)
3. **Очистить кеш Next.js:**
   ```bash
   rm -rf .next && npm run dev
   ```

### Проблема: Ошибки компиляции после git pull

```bash
# Переустановить зависимости
rm -rf node_modules .next
npm install
npm run dev
```

### Проблема: База данных не синхронизирована

```bash
# Применить все миграции
npm run db:migrate
```

## 🎯 Быстрый старт (основные команды)

```bash
# 1. Запустить разработку
npm run dev

# 2. Открыть в браузере
open http://localhost:3000

# 3. Остановить когда закончили (Ctrl+C или)
lsof -ti:3000 | xargs kill -9

# 4. Перед коммитом - проверить сборку
npm run build

# 5. Закоммитить изменения
git add -A && git commit -m "описание изменений"
git push origin master
```

## ℹ️ Полезная информация

### Структура портов

- **3000** - основной порт для dev/production
- **3001, 3002** - альтернативные порты (если 3000 занят)
- **5555** - Drizzle Studio (БД UI)

### Переменные окружения

Файл: `.env.local` (НЕ коммитить!)

Содержит:
- API ключи (Google AI, OpenAI)
- Строки подключения к БД
- Секреты NextAuth
