## 🤖 Возможности AI-агентов

### 📡 Интернет и поиск

#### Web Search (Brave Search API)
- **Описание:** Поиск актуальной информации в интернете
- **Возможности:**
  - Поиск новостей и текущих событий
  - До 20 результатов за запрос
  - Фильтрация по стране и языку
- **Требования:** `BRAVE_SEARCH_API_KEY` в `.env.local`
- **Файл:** [lib/ai/tools/web-search.ts](../lib/ai/tools/web-search.ts)

**Пример использования:**
```
Найди последние новости о GPT-5
Что нового в React 19?
```

---

### 👁️ Зрение и распознавание (Vision / Multimodal)

#### Image OCR (Google Gemini Vision)
- **Форматы:** JPG, JPEG, PNG
- **Возможности:**
  - Распознавание текста на фотографиях
  - Анализ скриншотов
  - Чтение сканированных документов
  - Извлечение текста из таблиц (markdown формат)
- **Модель:** Google Gemini 2.5 Flash
- **Файл:** [lib/ai/vision-ocr.ts](../lib/ai/vision-ocr.ts)

#### PDF OCR
- **Возможности:**
  - Чтение текстовых PDF
  - Распознавание отсканированных PDF
  - Многостраничные документы
- **Таймауты:** До 120 секунд для больших файлов
- **Модель:** Google Gemini 2.5 Flash

#### Загрузка файлов через чат
- **Лимит размера:** 20MB
- **Поддерживаемые форматы:**
  - Изображения: JPG, PNG
  - Документы: PDF, DOCX, TXT, MD
- **Обработка:**
  - DOCX → конвертация в TXT (mammoth)
  - TXT/MD → UTF-8 текст
  - PDF/Images → без конвертации (Claude multimodal)
- **Хранилище:** Vercel Blob Storage
- **Файл:** [app/(chat)/api/files/upload/route.ts](../app/(chat)/api/files/upload/route.ts)

**Пример использования:**
```
Прикрепи скриншот → "Что на этом изображении?"
Загрузи PDF → "Составь краткое резюме этого документа"
```

### 📄 База знаний (Knowledge Base)

#### Read Document
- **Путь:** `knowledge/` папка (security-restricted)
- **Форматы:** DOCX, PDF, TXT, MD, JPG, JPEG, PNG
- **Возможности:**
  - Чтение документов из базы знаний
  - OCR для изображений и PDF
  - Индексный файл: `knowledge/index.md`
  - Автоматические подсказки при ошибке пути
- **Безопасность:**
  - Directory traversal защита
  - Только `knowledge/` доступна
- **Файл:** [lib/ai/tools/read-document.ts](../lib/ai/tools/read-document.ts)

**Пример использования:**
```
Прочитай knowledge/index.md
Найди информацию в knowledge/Проекты/project.pdf
```

**Примечание:** В Этапе 3 планируется расширение системы проектов с привязкой базы знаний к конкретным проектам пользователей.

### ✨ Артефакты (Artifacts)

AI может создавать и обновлять интерактивные документы, которые отображаются справа от чата.

#### 1. Text Artifact (текстовые документы)
- **Возможности:**
  - Markdown форматирование (заголовки, списки, таблицы)
  - Копирование в буфер обмена
  - Предложения по улучшению текста (AI suggestions)
  - Потоковое создание (streaming)
- **Модель:** Google Gemini 2.5 Pro
- **Файлы:**
  - [artifacts/text/server.ts](../artifacts/text/server.ts)
  - [artifacts/text/client.tsx](../artifacts/text/client.tsx)

**Пример использования:**
```
Напиши статью о TypeScript
Создай документ с планом проекта
```

#### 2. Code Artifact (код)
- **Возможности:**
  - Синтаксис: Python, JavaScript, HTML/CSS, и др.
  - Интерактивный редактор с подсветкой синтаксиса
  - Копирование кода
  - Потоковое создание
- **Модель:** Google Gemini 2.5 Pro
- **Файлы:**
  - [artifacts/code/server.ts](../artifacts/code/server.ts)
  - [artifacts/code/client.tsx](../artifacts/code/client.tsx)

**Пример использования:**
```
Напиши функцию для сортировки массива на Python
Создай HTML страницу с формой логина
```

#### 3. Sheet Artifact (таблицы)
- **Возможности:**
  - CSV данные
  - Интерактивная таблица
  - Экспорт: копирование как CSV
  - Редактирование структуры
- **Модель:** Google Gemini 2.5 Pro
- **Файлы:**
  - [artifacts/sheet/server.ts](../artifacts/sheet/server.ts)
  - [artifacts/sheet/client.tsx](../artifacts/sheet/client.tsx)

**Пример использования:**
```
Создай таблицу с бюджетом проекта
Составь расписание встреч на неделю
```

**Важно:** Артефакты автоматически сохраняются в БД (таблица `documents`) и привязаны к пользователю.

### 🛠️ Утилиты и инструменты

#### Get Current Date
- **Возможности:**
  - ISO 8601 формат
  - Timestamp (Unix time)
  - Часовой пояс (Intl API)
  - Локализация (русский формат)
- **Файл:** [lib/ai/tools/get-current-date.ts](../lib/ai/tools/get-current-date.ts)

**Пример использования:**
```
Какой сегодня день?
Сколько дней до Нового года?
```

#### Get Weather
- **Возможности:**
  - Погода по координатам или названию города
  - Геокодирование (Open-Meteo API)
  - Текущая температура
  - Восход/закат солнца
  - Почасовой прогноз
- **API:** Open-Meteo (бесплатный)
- **Файл:** [lib/ai/tools/get-weather.ts](../lib/ai/tools/get-weather.ts)

**Пример использования:**
```
Какая погода в Москве?
Температура в Сан-Франциско?
```

#### Request Suggestions
- **Назначение:** Предложения по улучшению текстовых артефактов
- **Возможности:**
  - Анализ текста
  - До 5 умных предложений
  - Описание каждого изменения
  - Сохранение в БД (таблица `suggestions`)
- **Модель:** Google Gemini 2.5 Pro
- **Файл:** [lib/ai/tools/request-suggestions.ts](../lib/ai/tools/request-suggestions.ts)

**Пример использования:**
```
[Создаёшь текстовый артефакт]
"Предложи улучшения для этого текста"
```

## 🧠 AI-модели

| Модель | Назначение | ID | Провайдер |
|--------|------------|-----|-----------|
| **Gemini 2.5 Pro** | Основной чат, артефакты | `claude-sonnet-4` | Google AI |
| **Gemini 2.5 Flash** | Заголовки, OCR, быстрые задачи | `claude-haiku-3.5` | Google AI |

**Конфигурация:** [lib/ai/providers.ts](../lib/ai/providers.ts)

**Настройки:**
- **Temperature:** 1.0 (максимальная креативность)
- **Thinking budget:** 1024 токенов (для размышлений)
- **Step limit:** 5 шагов (max chain-of-thought)
- **Context window:** 140K токенов (из 200K, резерв 60K для ответа)

## ⚠️ Ограничения и требования

### ❌ Что НЕ поддерживается
- Прямой экспорт артефактов в PDF (только копирование текста)
- Экспорт таблиц в XLSX (только CSV через копирование)
- Запись файлов в `knowledge/` (только чтение)
- Загрузка файлов > 20MB
- Генерация изображений (DALL-E, Stable Diffusion)
- Аудио/видео обработка

### ✅ Требования
- **API ключи:**
  - `GOOGLE_GENERATIVE_AI_API_KEY` (обязательно)
  - `BRAVE_SEARCH_API_KEY` (опционально, для веб-поиска)
- **Хранилище:**
  - Vercel Blob Storage (для загрузки файлов)
  - PostgreSQL/Neon (для сохранения артефактов и suggestions)
- **Папка knowledge/:**
  - Должна существовать в корне проекта
  - Рекомендуется `knowledge/index.md` с индексом файлов
