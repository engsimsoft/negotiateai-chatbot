## 📖 О документе

Этот документ описывает все возможности и инструменты, доступные AI-агентам в приложении **Family AI Assistant**. В версии 2.1.1 реализована полная система из 8 специализированных агентов с автоматическим выбором AI моделей и UI индикатором активной модели.

## 🤖 Специализированные AI-агенты

**Версия:** 2.1.1 (Этап 3 завершен + UI улучшения)

> **Контекст решения:** См. [ADR 004: Agent System Decision](decisions/004-agent-system.md) -
> почему мы выбрали систему из 8 специализированных агентов с автоматическим выбором модели,
> какие альтернативы рассматривали, и какие последствия это имеет для проекта.

В приложении доступны 8 специализированных AI-агентов с уникальными промптами и поведением. Каждый агент автоматически использует оптимальную AI модель (Gemini 3 Pro или Gemini 2.5 Flash) в зависимости от типа задач. Пользователь может видеть активную модель в UI и при необходимости переключить режим вручную.

### 📊 Список агентов

| Агент | Иконка | Роли | Модель | Назначение |
|-------|--------|------|--------|------------|
| **Маркетолог** | 📊 | Marketer | Gemini 3 Pro | Профессиональный маркетинговый консультант: стратегия, аналитика, целевая аудитория, продвижение |
| **Копирайтер** | ✍️ | Marketer | Gemini 3 Pro | Создание продающих текстов: посты, рекламные тексты, заголовки, короткие абзацы с эмодзи |
| **Переводчик** | 🌐 | Marketer | Gemini 3 Pro | Точный перевод с учетом контекста: технические термины, сохранение стиля, многоязычность |
| **Кулинар** | 🍳 | Marketer | Gemini 2.5 Flash | Кулинарный помощник: подробные рецепты, советы по готовке, ингредиенты |
| **Астролог** | ⭐ | Marketer | Gemini 2.5 Flash | Нумерология и гороскопы: использует getCurrentDate для актуальных прогнозов |
| **Наставник** | 📚 | Both | Gemini 3 Pro | Личностный рост по методике Стивена Кови: 7 навыков, целеполагание, развитие |
| **Универсальный** | 💬 | Both | Gemini 2.5 Flash | Общий ассистент для любых задач: помощь по любым вопросам |
| **Одессит** | 😄 | Both | Gemini 2.5 Flash | Развлекательный агент: одесский юмор, байки, webSearch для информации |

### 🔑 Ключевые особенности

**Персонализация по ролям:**
- **Юлия (marketer)**: видит все 8 агентов
- **Владимир (engineer)**: видит 3 агента (Наставник, Универсальный, Одессит)

**Автоматический выбор AI модели:**
- **Gemini 3 Pro** - для профессиональных агентов (Маркетолог, Копирайтер, Переводчик, Наставник)
  - Продвинутый reasoning с dynamic thinking
  - 1M токенов контекст, 64K output
  - Цена: $2/$12 за 1M токенов
- **Gemini 2.5 Flash** - для развлекательных агентов (Кулинар, Астролог, Универсальный, Одессит)
  - Быстрее и дешевле
  - Оптимален для простых задач

**Режим "auto" по умолчанию (v2.1.1):**
- Все новые чаты автоматически создаются в режиме "auto"
- Система автоматически выбирает оптимальную модель для каждого агента
- Пользователь может переключить на конкретную модель через селектор (если нужно)
- Доступные режимы:
  - **Авто (рекомендуется)** - автоматический выбор на основе агента
  - **Gemini 3 Pro** - ручной выбор профессиональной модели
  - **Gemini 2.5 Flash** - ручной выбор быстрой модели
- **Файл конфигурации:** [lib/ai/models.ts](../lib/ai/models.ts)
- **Default значение:** `DEFAULT_CHAT_MODEL = "auto"`

**UI индикатор модели (v2.1.1):**
- **Расположение:** Badge в header чата рядом с именем агента
- **Отображает:**
  - В режиме "auto": "Авто" (мобильный) / "Авто (рекомендуется)" (десктоп)
  - При ручном выборе: "Gemini 3 Pro" или "Gemini 2.5 Flash"
- **Tooltip:**
  - Режим "auto": "Авто: {модель} (оптимально для этого агента)"
  - Ручной выбор: "Выбрано вручную: {модель}"
- **Адаптивный дизайн:**
  - Мобильный (< 1024px): показывает короткое название
  - Десктоп (≥ 1024px): показывает полное название
- **Иконка:** 🤖 (скрыта на мобильных устройствах)
- **Файл:** [components/chat-header.tsx:69-85](../components/chat-header.tsx#L69-L85)

**Приветственные сообщения:**
- Каждый агент приветствует пользователя при создании нового чата
- Уникальный текст приветствия для каждого агента

**Иконки в UI:**
- Карточки агентов на главном экране
- Иконка в header чата
- Иконки в истории чатов (sidebar)

### 🎯 Выбор агента

**Главный экран ([app/(chat)/page.tsx](../app/(chat)/page.tsx)):**
1. Пользователь видит карточки доступных агентов
2. Фильтрация по роли: `getAgentsByRole(user.role)`
3. При клике на агента создается новый чат с `agentId`
4. Редирект на `/chat/{id}?agentId={agentId}`

**Интеграция ([app/(chat)/api/chat/route.ts](../app/(chat)/api/chat/route.ts)):**
1. Загрузка промпта агента: `loadAgentPrompt(agentId)`
2. Автоматический выбор модели: `getModelForAgent(agentId)`
3. Использование: `streamText({ system: agentPrompt, model: modelId })`
4. Логирование: `Using agent ${agentId} with model ${modelId}`

### 👁️ Зрение и распознавание (Vision / Multimodal)

#### Image OCR (Google Gemini Vision)
- **Форматы:** JPG, JPEG, PNG
- **Возможности:**
  - Распознавание текста на фотографиях
  - Анализ скриншотов
  - Чтение сканированных документов
  - Извлечение текста из таблиц (markdown формат)
- **Модель:** Google Gemini 2.5 Flash
- **Файл:** [lib/ai/vision-ocr.ts](../lib/ai/vision-ocr.ts)

#### PDF OCR
- **Возможности:**
  - Чтение текстовых PDF
  - Распознавание отсканированных PDF
  - Многостраничные документы
- **Таймауты:** До 120 секунд для больших файлов
- **Модель:** Google Gemini 2.5 Flash

#### Загрузка файлов через чат
- **Лимит размера:** 20MB
- **Поддерживаемые форматы:**
  - Изображения: JPG, PNG
  - Документы: PDF, DOCX, TXT, MD
- **Обработка:**
  - DOCX → конвертация в TXT (mammoth)
  - TXT/MD → UTF-8 текст
  - PDF/Images → без конвертации (Claude multimodal)
- **Хранилище:** Vercel Blob Storage
- **Файл:** [app/(chat)/api/files/upload/route.ts](../app/(chat)/api/files/upload/route.ts)

**Пример использования:**
```
Прикрепи скриншот → "Что на этом изображении?"
Загрузи PDF → "Составь краткое резюме этого документа"
```

- **Файлы:**
  - [artifacts/text/server.ts](../artifacts/text/server.ts)

```
Создай документ с планом проекта
```

#### 2. Code Artifact (код)
- **Возможности:**
  - Синтаксис: Python, JavaScript, HTML/CSS, и др.

  - Потоковое создание
- **Модель:** Google Gemini 2.5 Pro
- **Файлы:**
  - [artifacts/code/server.ts](../artifacts/code/server.ts)

#### 3. Sheet Artifact (таблицы)
- **Возможности:**
  - CSV данные
  - Интерактивная таблица
  - Экспорт: копирование как CSV
  - Редактирование структуры
- **Модель:** Google Gemini 2.5 Pro
- **Файлы:**
  - [artifacts/sheet/server.ts](../artifacts/sheet/server.ts)
  - [artifacts/sheet/client.tsx](../artifacts/sheet/client.tsx)

**Пример использования:**
```

```

**Важно:** Артефакты автоматически сохраняются в БД (таблица `documents`) и привязаны к пользователю.

## 🧠 AI-модели

**Версия:** 2.1.0 (обновлено с Gemini 3 Pro)

| Модель | ID | Назначение | Агенты | Характеристики |
|--------|-----|------------|--------|----------------|
| **Gemini 3 Pro** | `gemini-3-pro` | Профессиональные задачи | Маркетолог, Копирайтер, Переводчик, Наставник | 1M контекст, dynamic thinking, $2/$12 за 1M |
| **Gemini 2.5 Flash** | `gemini-2.5-flash` | Развлечение, быстрые задачи | Кулинар, Астролог, Универсальный, Одессит | Быстрый, дешевый |
| **Gemini 2.5 Pro** | `gemini-2.5-pro` | Артефакты (suggestions) | - | Используется для генерации suggestions |

**Конфигурация:** [lib/ai/providers.ts](../lib/ai/providers.ts)

**Автоматический выбор модели:**
```typescript
// lib/ai/agents/index.ts
function getModelForAgent(agentId: AgentId): string {
  const agent = AGENTS.find(a => a.id === agentId);
  return agent?.defaultModel || "gemini-2.5-flash";
}
```

**Настройки (Gemini 3 Pro):**
- **Temperature:** 1.0 (максимальная креативность)
- **Thinking budget:** 1024 токенов (dynamic thinking для глубокого reasoning)
- **Step limit:** 5 шагов (max chain-of-thought)
- **Context window:** 1M токенов (огромный контекст)
- **Output:** 64K токенов максимум

**Настройки (Gemini 2.5 Flash):**
- **Temperature:** 1.0
- **Context window:** 200K токенов
- **Output:** Стандартный

## ⚠️ Ограничения и требования

### ❌ Что НЕ поддерживается
- Прямой экспорт артефактов в PDF (только копирование текста)
- Экспорт таблиц в XLSX (только CSV через копирование)
- Запись файлов в `knowledge/` (только чтение)
- Загрузка файлов > 20MB
- Генерация изображений (DALL-E, Stable Diffusion)
- Аудио/видео обработка

### ✅ Требования
- **API ключи:**
  - `GOOGLE_GENERATIVE_AI_API_KEY` (обязательно)
  - `BRAVE_SEARCH_API_KEY` (опционально, для веб-поиска)
- **Хранилище:**
  - Vercel Blob Storage (для загрузки файлов)
  - PostgreSQL/Neon (для сохранения артефактов и suggestions)
- **Папка knowledge/:**
  - Должна существовать в корне проекта
  - Рекомендуется `knowledge/index.md` с индексом файлов
