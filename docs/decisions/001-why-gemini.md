# ADR 001: Выбор Google Gemini в качестве AI модели

**Дата:** 2026-01-26
**Статус:** Принято

---

## Контекст

Проект изначально использовал Anthropic Claude API для чат-бота NegotiateAI (MIR.TRADE). После закрытия проекта MIR.TRADE была выполнена миграция на Google Gemini 2.5 Pro для нового применения - семейного AI-ассистента.

**Требования:**
- Streaming responses для быстрых ответов
- Поддержка AI SDK (Vercel)
- Хорошее качество генерации текста
- Приемлемая стоимость для личного использования
- Мультимодальность (текст, изображения)

---

## Решение

Использовать **Google Gemini 2.5 Pro** (`gemini-2.5-pro`) в качестве основной AI модели через `@ai-sdk/google`.

---

## Причины

1. **Free tier доступен** - Google предоставляет бесплатный tier для Gemini API, что идеально для семейного проекта с 2 пользователями

2. **Отличное качество** - Gemini 2.5 Pro показывает сопоставимое качество с Claude в задачах генерации текста, анализа и ассистирования

3. **Нативная интеграция с AI SDK** - Vercel AI SDK имеет официальную поддержку Google через `@ai-sdk/google` с полной поддержкой streaming

4. **Мультимодальность** - Gemini поддерживает работу с изображениями, что полезно для анализа документов и скриншотов

5. **Высокий rate limit** - Для personal use достаточно щедрые лимиты запросов

6. **Долгий контекст** - Gemini 2.5 Pro поддерживает до 1M токенов контекста, что позволяет работать с большими документами

---

## Последствия

### Плюсы

- Нулевая стоимость для текущего объема использования (free tier)
- Быстрые streaming responses
- Хорошее качество для технических и маркетинговых задач
- Мультимодальность из коробки
- Простая миграция благодаря AI SDK

### Минусы

- Нет function calling (tool use) как у Claude - пришлось адаптировать инструменты
- Немного другой стиль ответов по сравнению с Claude
- Зависимость от Google API (vendor lock-in)
- Free tier может измениться в будущем

---

## Альтернативы

### Альтернатива 1: Anthropic Claude

**Что это:** Исходная модель проекта, Claude 3.5 Sonnet

**Почему отклонили:**
- Платная модель даже для небольшого использования
- Для семейного проекта стоимость не оправдана
- Gemini показал достаточное качество

**Когда может быть лучше:**
- Если нужен function calling
- Если бюджет не ограничен
- Для сложных reasoning задач

### Альтернатива 2: OpenAI GPT-4

**Что это:** GPT-4 или GPT-4 Turbo от OpenAI

**Почему отклонили:**
- Также платная модель
- Более высокая стоимость по сравнению с Gemini
- Нет существенных преимуществ для use case

**Когда может быть лучше:**
- Большая экосистема плагинов
- Если уже используются другие OpenAI сервисы
- Для специфических задач где GPT-4 сильнее

### Альтернатива 3: Local LLM (Ollama)

**Что это:** Локальные модели через Ollama (Llama 3, Mixtral)

**Почему отклонили:**
- Требует мощное железо для качественных моделей
- Нет streaming из коробки
- Сложнее в настройке
- Качество ниже чем у cloud моделей

**Когда может быть лучше:**
- Полная приватность критична
- Офлайн использование
- Нет ограничений по железу

## Примечания

Миграция с Anthropic на Gemini прошла гладко благодаря абстракции Vercel AI SDK. Основные изменения были в:
- `lib/ai/providers.ts` - смена провайдера
- Отключение `smoothStream` для улучшения latency
- Адаптация AI tools (Brave Search остался работать)

Проект успешно развернут и работает на Vercel: https://negotiateai-chatbot-engsimsoft-gmailcoms-projects.vercel.app
