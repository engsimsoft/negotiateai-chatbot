# ADR 001: Почему прямой Anthropic API (а не через OpenRouter)

**Дата:** 2025-10-14
**Статус:** Устарело

---

## 🚨 Примечание о статусе

**Этот документ устарел.** Проект был успешно мигрирован с Anthropic API на **Google Gemini API** (через `@ai-sdk/google`).

Основная причина выбора прямого подключения — **нативная поддержка документов (DOCX/PDF)** — осталась ключевым фактором и при выборе Gemini, который предоставляет эту возможность через Vision API. Решение о миграции было принято для получения доступа к более продвинутым и экономически эффективным моделям.

---

## Контекст

Для проекта NegotiateAI Assistant нужно было выбрать способ подключения к Claude Sonnet 4.5. Рассматривались два варианта:

1. **Прямое подключение к Anthropic API** - официальный SDK от Anthropic
2. **Через OpenRouter** - агрегатор LLM API с единым интерфейсом

Требования:
- Чтение DOCX и PDF файлов напрямую
- Function calling (tools)
- Streaming responses
- Хорошая документация
- Надёжность

---

## Решение

Изначально выбрали **прямое подключение к Anthropic API**. Впоследствии это решение было пересмотрено в пользу **прямого подключения к Google Gemini API**.

---

## Причины (исторические, на момент принятия решения)

### 1. Нативная поддержка DOCX/PDF

**Anthropic API** имел нативную поддержку чтения документов через Messages API. **OpenRouter** на тот момент такой возможности не предоставлял, что требовало бы ручной конвертации файлов. Это было ключевым фактором.

### 2. Официальная документация и SDK

**Anthropic** предоставлял официальный TypeScript SDK с хорошей документацией, что упрощало разработку.

### 3. Прямой контроль и debugging

Прямое подключение к API провайдеру дает полный контроль над запросами, более понятные ошибки и убирает промежуточные слои, которые могут стать точкой отказа.

---

## Последствия (исторические)

### Плюсы

- ✅ **Нативное чтение DOCX/PDF** - ключевая функция для проекта.
- ✅ **Лучшая документация** и **Type safety** через официальный SDK.
- ✅ **Меньше зависимостей** и проще отладка.

### Минусы

- ❌ **Vendor lock-in** - привязка к одному провайдеру (сначала Anthropic, теперь Google).
- ❌ **Нет единого интерфейса** для быстрой смены моделей от разных провайдеров.
