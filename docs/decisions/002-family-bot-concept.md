# ADR 002: Концепция семейного AI-ассистента с ролями

**Дата:** 2026-01-26
**Статус:** Принято

---

## Контекст

После закрытия проекта MIR.TRADE (NegotiateAI чат-бот для переговоров) возник вопрос о дальнейшем использовании готовой кодовой базы. Проект был технически успешным (Next.js 15, Gemini API, NextAuth, PostgreSQL), но потерял бизнес-применение.

**Ситуация:**
- Рабочая кодовая база с современным стеком
- Опыт разработки AI чат-ботов
- Потребность в персональном AI-ассистенте для семьи
- Два пользователя с разными потребностями:
  - Владимир (инженер) - нужна помощь с кодом, архитектурой, debugging
  - Юлия (маркетолог) - нужна помощь с контентом, стратегией, аналитикой

---

## Решение

Переиспользовать кодовую базу NegotiateAI для создания **персонального семейного AI-ассистента** с поддержкой ролей и персонализации.

**Ключевые характеристики:**
- Приватный проект для 2 пользователей (без публичного доступа)
- Разные system prompts для каждой роли
- Персональные проекты с базой знаний
- Удаление guest режима

---

## Причины

1. **Переиспользование готового кода** - не тратить время на создание с нуля, база уже работает и протестирована

2. **Персонализация под роли** - возможность создать специализированных помощников для разных профессий (инженер vs маркетолог)

3. **Приватность** - семейный проект, не нужен публичный доступ, полный контроль над данными

4. **Практическая польза** - реальная потребность в AI-ассистенте для ежедневных задач обоих пользователей

5. **Продолжение обучения** - возможность продолжить изучение AI SDK, NextAuth, PostgreSQL в практическом применении

6. **База знаний** - возможность добавлять персональные документы и проекты для контекста

---

## Последствия

### Плюсы

- Экономия времени на разработке (переиспользование 80% кода)
- Реальное практическое применение для семьи
- Гибкая персонализация под каждого пользователя
- Возможность добавлять новые роли в будущем
- Полный контроль над приватностью
- Продолжение развития навыков AI-разработки

### Минусы

- Нужно поддерживать проект самостоятельно (не коммерческий)
- Ограничение на 2 пользователя (но это и не нужно больше)
- Необходимость адаптации UI/UX под семейное использование
- Удаление функций связанных с переговорами (специфика MIR.TRADE)

## Альтернативы

### Альтернатива 1: Использовать ChatGPT Pro

**Что это:** Подписка на ChatGPT Plus/Pro ($20-30/месяц)

**Почему отклонили:**
- Нет персонализации system prompts под роли
- Нет контроля над данными
- Нет интеграции с персональной базой знаний
- Стоимость подписки для каждого пользователя
- Нет возможности кастомизации

**Когда может быть лучше:**
- Если нет технических навыков
- Если нужен голосовой интерфейс
- Если не важна приватность

### Альтернатива 2: Создать новый проект с нуля

**Что это:** Начать разработку семейного ассистента с чистого листа

**Почему отклонили:**
- Займет недели работы
- Кодовая база NegotiateAI уже проверена и работает
- Не нужно изобретать велосипед
- Потеря времени на повторение уже сделанного

**Когда может быть лучше:**
- Если текущий стек не подходит
- Если архитектура требует полного переписывания
- Для обучающих целей "с нуля"

### Альтернатива 3: Использовать Notion AI или другие SaaS

**Что это:** Встроенные AI-ассистенты в продуктивных приложениях

**Почему отклонили:**
- Ограниченная функциональность
- Нет full conversation history
- Привязка к конкретному приложению
- Нет гибкости в настройке промптов
- Меньше контроля

**Когда может быть лучше:**
- Для простых задач
- Если уже используется это приложение
- Если не нужна персонализация

## Примечания

**Этапы реализации:**

1. **Этап 1: Очистка** (2-2.5 часа)
   - Обновление документации
   - Удаление специфики MIR.TRADE
   - Обновление брендинга

2. **Этап 2: Авторизация и роли** (1-2 недели)
   - Удаление guest режима
   - Добавление ролей в БД
   - Seed скрипт с двумя пользователями

3. **Этап 3: Персонализация** (2-3 недели)
   - Динамические system prompts по ролям
   - Система персональных проектов
   - База знаний per user

**Название проекта:**
- Старое: "NegotiateAI Chatbot" (MIR.TRADE)
- Новое: "Family AI Assistant"

**Пользователи и их специализации:**

| Имя | Роль | Специализация ассистента |
|-----|------|--------------------------|
| Владимир | Инженер | Технический помощник (код, архитектура, debugging) |
| Юлия | Маркетолог | Маркетинговый помощник (контент, стратегия, аналитика) |
