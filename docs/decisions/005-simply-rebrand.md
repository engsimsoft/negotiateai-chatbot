# ADR 005: Ребрендинг в Simply — платформу AI-агентов

**Дата:** 2026-01-28
**Статус:** Принято

---

## Контекст

После успешного завершения 4 этапов разработки Family AI Assistant возникло понимание потенциала проекта для более широкого применения.

**Текущее состояние (v2.5.0):**
- 9 специализированных AI-агентов
- Автоматический выбор модели (Gemini 3 Pro / 2.5 Flash)
- Система артефактов (text, презентации)
- 2 hardcoded пользователя (Владимир, Юлия)
- Роли: engineer, marketer

**Ограничения текущей архитектуры:**
- Агенты захардкожены в коде (нельзя добавить без деплоя)
- User.role вместо гибкой системы агентов
- Нет каталога агентов с UI
- Нет персонализации агентов пользователями
- Фиксированные 2 пользователя

---

## Решение

Трансформировать Family AI Assistant в **Simply** — платформу AI-агентов для российского рынка.

**Ключевые изменения:**

### 1. Философия
- **Apple-подход:** Лучше 10 идеально работающих агентов, чем 100 посредственных
- **Персонализация, не создание:** Пользователи адаптируют готовые агенты, а не создают с нуля

### 2. Архитектура агентов (ТЗ-1)
- Миграция агентов из кода в БД (таблицы `agents`, `user_agents`)
- Удаление User.role → агенты определяют функциональность
- Каталог агентов с UI (/agents, /agents/[slug])
- Агент-Помощник — системный роутер

### 3. Целевая аудитория
- Бизнес-пользователи в России без технического бэкграунда
- Оплата в рублях (ЮKassa, Тинькофф, СБП)
- Без VPN, без Visa/MC

### 4. Мультипровайдер (план)
- GPT, Claude, Gemini через единый интерфейс
- Smart Routing — автовыбор модели для экономии
- Vercel AI SDK уже поддерживает все провайдеры

---

## Причины

### 1. Потенциал роста
- Готовая инфраструктура (Next.js 15, Vercel AI SDK, PostgreSQL)
- Опыт разработки 4 этапов
- Реальная потребность в AI-инструментах на российском рынке

### 2. Санкции и доступность
- ChatGPT, Claude недоступны в России (санкции, нет карт)
- Российские решения либо низкого качества, либо дорогие
- Спрос на качественный AI с оплатой в рублях

### 3. Уникальное позиционирование
- Качество важнее количества (vs маркетплейсы с 1000+ агентов)
- Персонализация готовых агентов (vs сложное создание с нуля)
- Умный роутинг моделей (экономия для пользователя)

### 4. Техническая готовность
- Vercel AI SDK поддерживает мультипровайдер
- Drizzle ORM готов для расширения схемы
- Система артефактов уже работает

---

## Последствия

### Плюсы

- ✅ **Масштабируемость** — архитектура готова к росту
- ✅ **Монетизация** — подписки, pay-as-you-go
- ✅ **Российский рынок** — уникальная ниша
- ✅ **Качество** — фокус на проработанных агентах
- ✅ **Переиспользование** — 80% кода от Family AI

### Минусы

- ❌ **Больше работы** — миграция архитектуры, биллинг
- ❌ **Риски** — конкуренция, санкции могут измениться
- ❌ **Сложность** — мультипровайдер, умный роутинг
- ❌ **Поддержка** — нужна для платных пользователей

---

## Альтернативы

### Альтернатива 1: Остаться Family AI Assistant

**Что это:** Продолжить как приватный проект для 2 пользователей

**Почему отклонили:**
- Потенциал используется на 10%
- Нет роста, нет монетизации
- Архитектура уже переросла "семейный проект"

**Когда может быть лучше:**
- Если нет времени на развитие
- Если не важна монетизация

### Альтернатива 2: Маркетплейс агентов (как ConsoleX)

**Что это:** 100+ агентов, пользователи создают своих

**Почему отклонили:**
- Качество страдает при количестве
- Сложно модерировать user-generated агентов
- Конкуренция с крупными игроками

**Когда может быть лучше:**
- Если есть команда модераторов
- Если фокус на объеме, а не качестве

### Альтернатива 3: API-only продукт

**Что это:** Только API без UI, для разработчиков

**Почему отклонили:**
- Целевая аудитория — НЕ разработчики
- Теряем готовый UI
- Меньше дифференциация

**Когда может быть лучше:**
- Если целевая аудитория — разработчики
- Если нужна максимальная гибкость

### Этап 0: Документация и ребрендинг (текущий)
- Переименование Family AI → Simply
- Обновление всей документации
- Подготовка к ТЗ-1

### Этап 1: Архитектура агентов (ТЗ-1)
- Миграция агентов в БД
- Удаление User.role
- Каталог агентов с UI
- Агент-Помощник

### Этап 2+: Расширение
- Tool Activity UX (живая индикация)
- Мультипровайдер (GPT, Claude)
- Smart Routing
- Биллинг (подписки, рубли)
