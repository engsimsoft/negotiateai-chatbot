# ADR 044: Extract-on-Compression для Simply Chat

**Дата:** 2026-04-08
**Статус:** Принято

## Контекст

Simply Chat использует MiniMax M2.7 (204K контекст) и Gemini 3 Flash — модели без поддержки Anthropic Compaction API. Per-message extraction отключён (v3.77.0) как ненадёжный. Сообщения накапливаются в контексте, но факты не попадают в MIND — долговременная память деградирует.

## Решение

Пороговая система batch extraction: когда контекст Simply Chat приближается к лимиту модели → извлечь факты из старых сообщений → пометить как обработанные → при следующем запросе загрузить меньше.

**Два порога:**
- 80% (160K) + пауза ≥ 10 минут → fire-and-forget batch extraction
- 95% (190K) → немедленная extraction без проверки паузы

**Механизм:**
1. Колонка `extractedAt` в Message_v2 — NULL = не обработано
2. `getMessagesByChatId(excludeExtracted: true)` — загрузка только необработанных
3. `batchExtractFacts()` — один вызов Sonnet на batch из ≤50 сообщений
4. Существующий pipeline: embed (Voyage) → dedup (Haiku) → store (pgvector)
5. Ночной cron (memory-profile) — страховка для сообщений >24ч

## Причины

1. **Экономичнее per-message**: один вызов Sonnet на 50 сообщений вместо 25 вызовов
2. **Надёжнее saveFact**: AI не решает когда писать — система управляет автоматически
3. **Safety-cap 180K**: защита от бесконтрольного роста при сбоях extraction
4. **Fire-and-forget**: не блокирует ответ пользователю
5. **Ночной cron**: подхватывает случаи когда пользователь ушёл надолго

## Последствия

**Плюсы:**
- Факты из Simply Chat попадают в MIND (было: никогда после v3.77.0)
- Контекст автоматически «облегчается» — извлечённые сообщения не загружаются
- Один механизм для всех моделей Simply (MiniMax, Gemini, Sonnet think)
- Dedup pipeline предотвращает дублирование даже при race conditions

**Минусы:**
- Факты попадают в MIND не сразу (только при пороге или cron)
- Batch extraction дорогой (~$0.24 за 50 сообщений с Sonnet)
- Нет extraction для коротких разговоров (контекст не достигает порога — cron подхватит через 24ч)

## Альтернативы

1. **Per-message extraction** — отклонено: дорого, ненадёжно (отключено в v3.77.0)
2. **saveFact tool** — отклонено: AI галлюцинирует вызовы, удалено в v3.77.0
3. **Compaction API** — невозможно: MiniMax/Gemini не поддерживают Anthropic API
4. **Включить compaction для think-mode (Sonnet)** — отклонено: усложнение ради одного сообщения, один механизм проще
